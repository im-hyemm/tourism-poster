# 지역점수 편향 재검토 노트북 작성 계획

## 요약

- 기존 노트북과 생성 스크립트는 수정하지 않는다.
- 최종 노트북은 `notebooks/06_Score/260726_연고관광_클러스터별_지역점수.ipynb`, 생성 스크립트는 `script/260726_연고관광_클러스터별_지역점수.py`로 관리한다.
- 현행 전국 상위 20개에 인구감소지역이 0개이고 특별·광역시 소속이 11개인 원인을 지표 방향, 중복, 규모효과, 후보 필터 순서로 나누어 진단한다.
- 단일 점수 대신 사용자가 선택한 `전환 잠재력 × 공급 준비도` 2축 포트폴리오를 주 결과로 사용하고, 대표 6개 점수안을 비교한다.

## 구현 내용

### 1. 현행 점수 재현과 편향 진단

- 현재 노트북의 점수와 상위 20개를 동일하게 재현해 새 계산의 기준선으로 둔다.
- 다음 문제를 수치로 확인한다.
  - 절대 연고방문 규모가 수요지수 `D`의 50%를 차지하는 규모효과
  - 시설 수와 밀도 모두 도시형 지역에 유리할 가능성
  - `flex=max(A, T)`가 평균 50점인 두 지수보다 구조적으로 점수를 높이는 문제
  - `E`, `E_family`, `B` 등 중첩 공급지표의 중복 반영
  - CASE 1·2·4 대표여행 지표 `P·H·Q`를 CASE 2 지원점수에 넣는 분석대상 불일치
  - 지원순위는 대표여행 신뢰도로 필터링하지만 민감도 상위 20개는 전체 229개로 계산되는 기준 불일치
  - CASE 2 표본이 30건 미만인 지역도 상위 지원목록에 포함되는 문제
- “대도시”를 임의로 정의하지 않고 `특별·광역시 자치구 / 기타 시 / 군 / 기타` 행정유형별 점수와 상위권 비중을 비교한다.

### 2. 공통 지표 재구성

- `V`: CASE 2·3 가중 방문규모의 전국 백분위
- `R`: 전체 여행 중 CASE 2·3 비중의 전국 백분위
- `D50=0.5V+0.5R`: 현행 수요지수
- `D30=0.3V+0.7R`: 규모효과를 줄인 균형 수요지수
- `D0=R`: 절대규모를 제거한 규모중립 수요지수
- `G`: `CASE3/(CASE2+CASE3)`의 백분위인 관광전환 필요
- `POT=0.6D30+0.4G`: 정책 전환 잠재력
- `SUP`: 현행 클러스터별 가중치에서 물리적 관광·식음·숙박·교통·상권 공급만 재정규화한 뒤, N=50 보정 군집 구성비로 결합한 공급 준비도
- `flex`는 수정안에서 `max(A,T)` 대신 `0.5A+0.5T`를 사용한다.
- `P·H·Q`는 수정 점수에서 제외하고 후보지역 설명용 보조지표로만 유지한다.
- 시설 수:밀도 결합은 기본 50:50을 유지하되 20:80, 80:20 변형으로 민감도를 확인한다.

### 3. 대표 6개 점수안과 2축 포트폴리오

1. `현행안`: 기존 최종점수 완전 재현
2. `규모중립안`: `0.60×(0.6D0+0.4G)+0.40×SUP`
3. `수요우선안`: `0.70×D30+0.15×G+0.15×SUP`
4. `전환우선안`: `0.30×D30+0.50×G+0.20×SUP`
5. `지원필요안`: `0.60×POT+0.40×(100-SUP)`
6. `실행준비안`: `0.60×POT+0.40×SUP`

- 주 결과는 `POT`와 `SUP`를 각각 축으로 사용하는 포트폴리오다.
- 전국 CASE 2 N≥30 지역의 중앙값을 기준으로 `즉시실행형`, `기반보강형`, `공급활용형`, `관찰형`을 구분한다.
- 6개 점수안별 상위 20개, 행정유형 구성, 인구감소지역 수, 순위상관, 상위 20개 교집합을 비교한다.
- `D`의 절대규모 비중 0·30·50%, 공급 수:밀도 20:80·50:50·80:20, 구성비 보정 N=30·50·70을 한 요인씩 바꾸어 결과 안정성을 점검한다.

### 4. 인구감소지역 전용 셀

- 인구감소지역 89개 결합을 별도 셀에서 검증하고, 군위군은 기존의 명시적 분석키 교차표를 적용한다.
- 점수 계산 후 인구감소지역을 필터링하며, 전국 순위를 재사용하지 않고 89개 지역 안에서 6개 안별 순위를 다시 계산한다.
- CASE 2 N≥30은 지원 검토 후보, N<30은 관찰 후보로 분리한다.
- 별도 셀에서 다음을 출력한다.
  - 6개 안별 인구감소지역 상위 20개
  - 상위 20개 공통·교체 지역
  - 기반보강형과 즉시실행형 후보
  - 표본 수, `POT`, `SUP`, 지원필요점수, 실행준비점수와 주요 군집

## 시각화와 산출물

- 현행 상위 20개의 지표군별 점수 기여도
- 행정유형별 현행 점수 분포와 상위 20개 구성
- 6개 안별 상위 20개의 행정유형·인구감소지역 구성비
- 6개 안의 Spearman 순위상관 및 상위 20개 교집합 히트맵
- 전체 지역의 `전환 잠재력 × 공급 준비도` 포트폴리오 산점도
- 인구감소지역만 필터링한 포트폴리오 산점도
- 인구감소지역 상위 후보의 잠재력·공급 준비도 비교 점그래프
- 모든 그림은 프로젝트 스타일을 적용해 900 DPI로 저장하고, 결과표와 함께 새 노트북 전용 `outputs/` 디렉터리에 기록한다.

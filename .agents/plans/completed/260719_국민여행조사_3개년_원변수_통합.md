# 국민여행조사 3개년 원변수 통합본 제작 계획

## 목표

2023·2024·2025년 국내여행 SAV의 공식 원변수를 최대한 보존하면서, 연도 간 문항
이동과 코드 차이를 추적할 수 있는 분석용 통합본을 제작한다.

## 확정 기준

- 원본 SAV는 읽기 전용으로 사용한다.
- 공식 코드북의 `국내여행 코드 > 원변수`만 포함한다.
- 영문자로 시작하는 SAV 변수는 공식 원변수 목록과 일치한다.
- 원변수 수는 2023년 1,376개, 2024년 1,235개, 2025년 1,427개다.
- 원변수 합집합은 1,719개, 같은 이름의 3개년 공통 변수는 918개다.
- 같은 이름보다 코드북의 문항 의미를 우선한다.
- 결합 키는 `YEAR + ID`로 만들고 `ID`의 연도 간 유일성을 가정하지 않는다.
- `WT_DOM`은 연도별 모집단 추정에 사용하며 3개년 고유 인구 가중치로 합산하지
  않는다.

## 변수 대응표 설계

다음 열을 포함한다.

- `year`: 조사 연도
- `source_name`: SAV 원변수명
- `canonical_name`: 통합본 변수명
- `source_label`: SAV 변수 설명
- `question_group`: 문항 의미 그룹
- `mapping_status`: `direct`, `renamed`, `year_only`, `review`
- `code_status`: `same`, `expanded`, `recode`, `unlabeled`
- `available`: 해당 연도 존재 여부
- `notes`: 분기, 신규 범주, 의미 변경 등

## 실행 단계

### 1. 원변수 인벤토리

- [x] 세 SAV의 메타데이터를 `metadataonly=True`로 읽는다.
- [x] 영문자 시작 변수만 추출하고 연도별 원변수 수를 검산한다.
- [x] 변수 존재 패턴과 값 라벨 정의를 변수 대응표 초안에 기록한다.

### 2. 문항 의미 매핑

- [x] 2024·2025년 변수명을 기본 canonical 이름으로 사용한다.
- [x] 2023년 A문항 이동을 공식 코드북으로 매핑한다.
    - `A2/A2A → A1/A1A`
    - `A3_* → A2_*`, `A4_* → A3_*`, `A5_* → A4_*`
    - `A6*/A7*/A8*/A9* → A5*/A6*/A7*/A8*`
    - `A10/A10A_* → A9/A9A_*`, `A11 → A10`, `A12 → A11`
- [x] 위 규칙은 접두사 일괄 치환하지 않고 실제 문항 설명이 일치하는 열에만
      적용한다.
- [x] 2023년 `A1_*`과 신규 문항은 `year_only`로 보존한다.
- [x] canonical 이름이 한 연도 안에서 중복되지 않는지 확인한다.

### 3. 코드 조화

- [x] 코드와 의미가 같은 변수는 원코드를 유지한다.
- [x] 신규 범주는 삭제하거나 임의 통합하지 않고 `expanded`로 기록한다.
- [x] 의미가 달라진 같은 이름 변수는 재코딩하지 않고 먼저 다른 canonical 열로
      분리한다.
- [x] `D_TRA*_CASE`는 실제 관측 코드 1~5를 유지하고 메타데이터의 미관측 6~9는
      사용하지 않는다.
- [x] 재코딩이 꼭 필요한 변수만 별도 harmonized 열을 만들고 원값을 덮어쓰지
      않는다.

### 4. 연도별 전처리와 결합

- [x] 연도별 원변수만 읽고 `YEAR`, `SOURCE_FILE`, `RECORD_KEY`를 추가한다.
- [x] 변수 대응표에 따라 분석용 복사본의 열을 canonical 이름으로 변경한다.
- [x] 연도 한정 변수까지 포함해 outer concat한다.
- [x] 구조적 비해당과 연도 미존재 결측을 구분할 수 있도록 대응표의
      `available`과 `notes`를 사용한다.
- [x] 통합 데이터를 csv으로 저장한다.

### 5. 품질 검증

- [x] 연도별 행 수와 통합 후 행 수 합계를 대조한다.
- [x] `YEAR + ID`의 결측과 중복을 확인한다.
- [x] 분석변수가 통합본에 포함되지 않았는지 확인한다.
- [x] 연도별 원변수 수와 원변수 합집합을 다시 검산한다.
- [x] canonical 매핑 전후의 비결측 수와 원값이 보존되는지 확인한다.
- [x] 값 라벨 변수에서 정의 밖 관측 코드가 있는지 확인한다.
- [x] `WT_DOM`의 결측·비양수 값과 연도별 분포를 확인한다.
- [x] 지역 변수는 전용 지역코드와 결합하고 미매칭을 확인한다.
- [x] 통합 노트북을 처음부터 끝까지 재실행한다.

## 완료 기준

- 통합본의 모든 값이 원본 SAV 또는 명시된 harmonized 열로 추적된다.
- 변수 대응표에서 모든 연도·원변수의 처리 상태를 확인할 수 있다.
- 같은 이름이지만 의미가 다른 문항이 한 canonical 열에 섞이지 않는다.
- 연도 한정 변수와 신규 범주가 삭제되지 않는다.
- 노트북 실행 오류가 없고 핵심 수치가 저장된 산출물과 일치한다.

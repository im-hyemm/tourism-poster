### 연도별 변수 패턴 분석

- 2023→2024와 2024→2025를 구분해 다음을 분석한다.
    - 원변수·접두사별 변수 수
    - 추가·삭제·이름 변경 변수
    - 질문 라벨, 값 라벨, 자료형과 응답 단위 변화
    - A·D·D_TRA·DQ·SA·MON_EXP 계열 구조
    - 여행 슬롯, 방문지 슬롯, 항목·순위 반복 구조
- 변수명을 질문 블록, 문항 번호, 여행 슬롯, 방문지 슬롯, 항목·순위와 측정 역할로 분해한다. 정규식은 후보 탐색용으로만 사용하고 최종 통합은 명시적 규칙표로 결정한다.
- 접두사의 의미를 별도 축으로 보존한다.
    - `N`: 1인 기준 비용
    - `P`: 비용 포함·공동 이용 인원 수
    - `T`: 기타 서술형 텍스트
    - `M`: 동반자 등 반복응답
- 비용 원액·총액·1인 비용·인원 수·텍스트는 같은 질문에 속하더라도 서로 다른 변수로 유지한다.

### D_TRA 최대 슬롯 통합

- 여행 슬롯은 연도별 교집합이 아니라 관측된 최대 슬롯 6개를 기준으로 한다.
    - 2023: `D_TRA1~6`
    - 2024: `D_TRA1~5`
    - 2025: `D_TRA1~6`
- 2024년 `D_TRA6_*`는 통합 스키마에 포함하지만 모두 `NA`로 둔다.
- 변수 사전에는 2024년 D_TRA6을 `available=False`, `treatment=not_collected`로 기록한다.
- 2023·2025년 `D_TRA6_*`는 원값과 자료형을 보존한다.
- 방문지 슬롯은 확인된 최대 17개까지 유지한다.
- 여행 존재 여부는 `D_TRA*_CASE`의 비결측 여부로 판단한다. 특정 CASE 코드 집합으로 여행을 제외하지 않는다.
- CASE는 코드북 정의 범위와 실제 관측 범위를 나눠 기록한다.
    - 코드북에는 6번 등이 정의될 수 있다.
    - 현재 SAV의 실제 관측값은 세 연도 모두 1~5다.
    - 향후 6이 관측되더라도 임의로 제거하지 않고 공식 값 라벨에 따라 처리한다.

### 2023년 가장 최근 여행과 이동수단

- 2023년 가장 최근 여행은 CASE 값의 종류와 관계없이 실제 존재하는 D_TRA 슬롯 중 날짜가 가장 늦은 여행으로 결정한다.
- 날짜 비교에는 `D_TRA*_SYEAR`, `SMONTH`, `SDAY`를 사용한다.
    - 날짜가 같으면 슬롯 번호가 큰 여행을 선택한다.
    - 날짜가 일부 결측이면 존재하는 슬롯 중 가장 큰 슬롯 번호를 사용하고 해당 사례 수를 노트북에 출력한다.
- 기존 자료에서는 슬롯 번호가 커질수록 여행일이 최근인 패턴이 거의 일관되지만, 고정 슬롯을 가정하지 않고 응답자별 날짜로 선택한다.
- 2023년 원변수 `A1_1~3`을 가장 최근 여행 슬롯의 다음 열에 같은 순위끼리 복사한다.
    - `D_TRA{k}_B7A_1~3`: 지역간 주요 이동수단
    - `D_TRA{k}_B7B_1~3`: 지역내 주요 이동수단
- 가장 최근 여행 외의 실제 여행 슬롯은 `-1=해당 여행의 이동수단 미조사`로 둔다.
- 여행 자체가 없는 슬롯은 `NA`로 둔다.
- `A1_2`나 `A1_3`처럼 개별 순위 응답이 원래 결측이면 해당 순위는 원결측을 유지하며 유효값을 추정하지 않는다.
- 공식 유저가이드의 “무작위 선정 여행” 설명과 사용자 제공 “가장 최근 여행” 규칙의 차이를 변수 사전과 note에 기록하고, 전처리는 사용자 지정 규칙을 적용한다.

### 의미 기반 A계열 통합

- 2023년 이동수단 `A1_*`은 위 D_TRA 이동수단 파생에 사용하고, 2024·2025의 여행사 상품 문항 `A1*`과 합치지 않는다.
- 나머지 2023 A문항 번호 이동은 2024·2025의 문항 의미를 기준으로 연결한다.
- 번호 이동은 `A*`뿐 아니라 같은 질문을 나타내는 `NA*`, `PA*` 등 관련 접두사 전체에 적용한다.
- 같은 이름이어도 질문 대상·단위·값 의미가 다르면 분리하고, 이름이 달라도 질문·단위·값 코드가 같으면 통합한다.
- 값 범주가 확대된 변수는 공통 의미로 근거 있게 재코딩할 수 있을 때만 포함한다.
- 일반적인 연도 전용 신규 문항은 3개년 비교 중심 통합본에서 제외하되, D_TRA 최대 슬롯과 이동수단처럼 명시된 예외는 포함한다.

## 검증 계획

- D_TRA 슬롯별 시작일을 비교해 여행 슬롯의 실제 시간 순서를 연도별로 출력한다.
- 각 응답자에서 선택된 최근 여행 날짜가 다른 모든 유효 슬롯보다 늦거나 같은지 검증한다.
- CASE 값은 공식 값 라벨에 정의된 범위 안인지 확인하되 `{1,2,4}`와 A 응답의 일치를 통합 근거로 사용하지 않는다.
- 2023 이동수단은 응답자별 가장 최근 여행 슬롯 한 곳에만 복사되었는지 확인한다.
- 복사된 B7A/B 순위 값이 원본 `A1_1~3`과 일치하는지 확인한다.
- 다른 실제 여행 슬롯은 `-1`, 여행이 없는 슬롯은 `NA`인지 확인한다.
- 2024년 D_TRA6은 모두 `NA`이며 변수 사전에 미수집으로 표시되는지 확인한다.
- 2023·2025년 D_TRA6의 원값과 비결측 수가 보존되는지 확인한다.
- A·N·P 계열의 번호 이동을 라벨·단위·값 코드로 검산한다.
- 연도별 행 수, `YEAR + ID` 유일성, 통합 전후 원값과 비결측 수를 대조한다.
- 변수 사전의 열 이름·순서·개수가 통합 CSV와 정확히 일치하는지 확인한다.
- 모든 검증과 제외 사유는 실행된 노트북 출력에만 남긴다.

## 확정 가정

- 최종 자료는 응답자·조사회차 1행의 wide 구조다.
- D_TRA 여행 슬롯은 최대 6개, 방문지 슬롯은 최대 17개를 사용한다.
- 2023 A계열은 CASE 종류와 관계없이 실제 국내여행 중 가장 최근 여행에 연결한다.
- 2023 이동수단은 최근 여행의 지역간·지역내 양쪽에 동일 순위로 복사한다.
- 이전 실제 여행의 이동수단 미조사는 `-1`, 여행 없음과 2024년 미수집 D_TRA6는 `NA`로 구분한다.
- 사전 파일명은 `national_travel_survey_2023_2025_codebook.csv`를 사용한다.
- 기존 생성 스크립트와 기존 통합 산출물은 수정·삭제·덮어쓰지 않는다.

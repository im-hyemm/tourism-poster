# 사전 층화 기반 연고관광 군집분석 재설계

## 요약

- 기존 노트북은 보존하고 새 노트북과 생성 스크립트를 만든다.
- CASE 2 여행을 `당일 1,505건`과 `숙박 2,314건`으로 먼저 구분한 뒤 각각 독립적으로 분석한다.
- 기존 F2 소비 확장형을 유지하되 층화에 사용한 `숙박 여부·숙박일수`는 군집 입력에서 제외한다.
- 유효한 5개 모형 조합을 비교하며, 각 모형의 K는 자체 목적함수 스크리 플롯의 객관적 엘보우로 정한다.
- 자체·공통 Gower 실루엣의 Pareto 우월성과 안정성을 이용해 층별 최종 모형을 선택한다.

## 분석 구현

- 새 산출물:
  - `notebooks/03_Modeling/260719_연고관광_사전층화_클러스터링_2025년.ipynb`
  - 대응 생성 스크립트와 `stratified_cluster_*` 접두사의 표·그림
- 입력 변수:
  - 기존 F2의 준비·활동·동반·숙박시설·이동·방문·소비 변수 유지
  - `overnight_trip`, `nights` 제외
  - 층 안에서 분산이 0인 변수는 자동 제외하고 목록 기록
  - 교통 코드 오류를 바로잡아 자가용 계열은 `자가용·렌터카`, 대중교통은 `철도·항공·선박·지하철·버스`로 재분류
  - `WT_DOM`은 군집 생성에는 사용하지 않고 군집 규모와 프로파일 추정에만 사용
- 층별 비교 모형:
  1. Robust scaling·원-핫 공간 + K-means
  2. 동일 유클리드 공간 + K-medoids
  3. 영역 균형 Gower 거리 + K-medoids
  4. 32→8→32 오토인코더 임베딩 + K-means
  5. 동일 오토인코더 임베딩 + K-medoids
- 오토인코더는 기존 구조·조기 종료·5개 시드를 유지하고, 기존의 `검증 손실` 표기는 실제 값에 맞게 `검증 R²`로 바로잡는다.

## K 및 최종 모형 선택

- 각 층·모형별로 `K=1~8`의 목적함수를 계산한다.
  - K-means: 군집 내 제곱거리 합
  - K-medoids: 관측치와 medoid 간 거리 합
- 시드별 목적함수 곡선을 `K=1에서 1, K=8에서 0`으로 정규화한 뒤 평균한다.
- 시작점과 끝점을 연결한 직선에서 정규화 곡선이 가장 멀어지는 지점을 객관적 엘보우 K로 선택하며, 동률이면 작은 K를 선택한다.
- `K=2~8`에 대해 자체 공간과 공통 Gower 공간의 실루엣 곡선을 함께 제시한다. 최종 K에서는 전체 표본 실루엣을 다시 계산한다.
- 후보 통과 기준:
  - 최소 군집 비중 5% 이상
  - 5개 시드 간 평균 ARI 0.70 이상
- 통과 후보 중 자체·Gower 실루엣의 Pareto frontier를 구한다. 여러 후보가 남으면 공통 Gower 실루엣, 자체 실루엣, 안정성 ARI 순으로 선택한다.
- 조건을 통과하는 후보가 없으면 해당 층은 최종 군집을 강제로 선택하지 않고 `안정적인 하위 군집 근거 없음`으로 결론 낸다.

## 결과와 검증

- 층·모형별 원 목적함수, 정규화 스크리 값, 엘보우 K, 두 실루엣, ARI, 최소 군집 비중을 표로 저장한다.
- 스크리 플롯은 모형별 패널로 분리하고 엘보우 K를 직접 표시한다. 자체·Gower 실루엣은 별도 비교 그림으로 만든다.
- 최종 군집은 입력변수 lift, 가중 구성비, 소비수준·소비구조, 만족도·재방문·추천 의향으로 해석한다. 소비는 군집 정의 변수임을 명시하고 만족도 등만 외부 프로파일로 구분한다.
- `tourism` 환경에서 생성 스크립트 실행 후 노트북을 처음부터 끝까지 재실행한다.
- CASE 2 총 3,819건 및 층별 1,505/2,314건, 키 중복, Gower 행렬 대칭성·대각선 0, 양의 가중치, 군집 크기와 저장 표 일치를 검증한다.
- 저장된 300 DPI 그림에서 한글, 범례, 축 단위, 엘보우 표시와 잘림 여부를 직접 확인한다.

## 가정

- 기존 분석 노트북과 기존 `cluster_*` 산출물은 수정하거나 덮어쓰지 않는다.
- K는 모형별로 독립 선택하므로 최종 비교표에 서로 다른 K의 후보가 함께 나타날 수 있다.
- Gower 거리에 K-means를 직접 적용하는 부적절한 조합은 만들지 않는다.

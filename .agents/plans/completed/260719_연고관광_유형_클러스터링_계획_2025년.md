# 2025년 국민여행조사 연고관광 유형 클러스터링 계획

## 1. 연구 개요

### 연구 목적

2025년 국민여행조사의 국내여행 중 관광·휴양 활동을 포함한 가족·친지·친구
방문 여행을 대상으로 여행 준비, 관광활동, 동반 형태, 체류, 이동과 소비 특성에
따른 연고관광 유형을 도출한다. 도출된 유형의 만족도, 재방문 의향과 지역별
분포를 비교해 지역관광 활성화 전략의 정책 대상을 구체화한다.

### 핵심 연구 질문

1. 관광활동을 포함한 연고 방문은 몇 개의 안정적인 행동유형으로 구분되는가?
2. 각 유형을 구분하는 핵심 여행행태는 무엇인가?
3. 유형별 만족도, 재방문 의향, 추천 의향과 방문지역 분포는 어떻게 다른가?
4. 얕은 오토인코더의 비선형 임베딩은 해석 가능한 전통 군집보다 추가적인
   구조를 발견하는가?

### 용어와 주장 범위

- 분석 대상은 국민여행조사 여행유형 2인 `관광·휴양 활동을 포함한
  가족·친지·친구 방문`이다.
- 이를 데이터 분석에서는 `연고 기반 방문` 또는 `연고관광`으로 부른다.
- 해당 문항은 출생지, 법적 고향, 관계의 지속기간과 반복 방문 여부를 직접
  측정하지 않는다.
- 군집 간 차이는 조사자료에서 관찰된 연관성으로 해석하며 정책의 인과효과로
  표현하지 않는다.

### 분석 단위와 키

- 분석 단위: A계열 본설문의 대상이 된 개별 국내여행
- 기본 키: `ID + SELECTED_TRIP_NO`
- 가중치: `WT_DOM`
- 모집단 해석 단위: CHECK로 선정된 CASE 2 여행

### 선정여행 식별 규칙

1. `D_TRA1_CHECK`부터 `D_TRA6_CHECK`까지 확인한다.
2. 값이 문자열 `Y`인 슬롯을 `SELECTED_TRIP_NO`로 정의한다.
3. 응답자마다 `CHECK == "Y"`인 슬롯이 정확히 하나인지 검증한다.
4. 선정 슬롯의 `D_TRA{k}_CASE == 2`인 응답자만 추출한다.
5. 선정 슬롯의 D계열 변수와 응답자 행의 A계열 변수를 결합한다.

최고 슬롯이나 날짜 기준 최근 여행을 A계열 대상 여행으로 대신 사용하지 않는다.
날짜와 슬롯 순서는 선정여행 검산에만 사용한다.

### 사전 확인 결과

- A계열 응답 및 `CHECK == "Y"` 선정여행: 23,988건
- 응답자별 CHECK 선정여행 수: 모두 1건
- CHECK 선정여행의 CASE 분포:
  - CASE 1: 19,541건
  - CASE 2: 3,819건
  - CASE 4: 628건
- 최종 분석 후보 표본: CASE 2 선정여행 3,819건
- CHECK 선정여행과 날짜 기준 최근 여행이 다른 사례: 265건
- CHECK 선정 CASE 2이지만 최근 여행이 다른 CASE인 사례: 20건

기존 계획 문서의 `D_TRA*_CHECK` 전부 결측 가정과 달리 실제 2025년 SAV에는
빈 문자열과 `Y`가 관측된다. 2025년 분석은 실제 SAV의 문자열 값을 우선한다.

## 3. 데이터 품질 검증

### 원자료 검증

- 전체 행·열 수와 `ID` 유일성을 확인한다.
- `WT_DOM`의 결측, 비양수, 극단값을 확인한다.
- 필요한 A·D·인구통계 변수가 SAV와 변수표에 모두 존재하는지 확인한다.
- 원코드를 보존하고 라벨 열이나 분석용 파생변수를 별도로 만든다.

### 선정여행 검증

- `CHECK == "Y"`가 응답자마다 0개, 1개, 2개 이상인 사례 수를 출력한다.
- CHECK 선정 슬롯과 A계열 핵심 변수의 비결측이 대응하는지 확인한다.
- 선정 슬롯 CASE가 2인 3,819건이 재현되는지 확인한다.
- 선정 슬롯의 날짜, 비용, 여행일수, 방문지와 이동수단이 정확히 연결됐는지
  슬롯별 원값 표본 검사를 수행한다.

### 설문 분기와 결측 검증

- 구조적 비해당, 무응답, 시스템 결측과 유효한 0을 구분한다.
- 다중응답 문항은 문항별 선택률의 분모를 명시한다.
- 변수별 결측률과 구조적 비해당률을 따로 출력한다.
- 결측률이 높거나 CASE 2에서 의미가 불명확한 변수는 군집 입력에서 제외한다.

## 4. Gower 거리의 역할

Gower 거리는 수치형, 범주형, 이진형 변수가 혼합된 자료에서 두 사례의 차이를
하나의 거리로 계산한다. 각 변수의 차이를 0에서 1 사이로 바꾼 뒤 유효 변수의
차이를 평균한다.

- 수치형: 두 값의 절대 차이를 해당 변수의 범위로 나눈다.
- 범주형·이진형: 같으면 0, 다르면 1로 둔다.
- 결측: 두 사례를 비교할 수 없는 변수만 평균에서 제외한다.
- 최종 거리 0은 두 여행의 특성이 같음을, 1은 최대한 다름을 의미한다.

국민여행조사는 비용과 일행 수 같은 수치형 변수, 이동수단과 주 활동 같은
범주형 변수, 예약 여부와 가족집 숙박 여부 같은 이진형 변수가 섞여 있으므로
Gower 거리가 적합하다. Gower 거리와 K-medoids를 결합하면 각 군집의 중심을
실제 관측 여행인 medoid로 제시할 수 있어 해석에도 유리하다.

다중응답 항목 수가 많은 영역이 거리를 지배하지 않도록 개별 변수 수가 아니라
다음 분석 영역별 총가중치를 균형 있게 설정한다.

1. 여행 준비
2. 관광활동
3. 동반 형태
4. 체류·숙박
5. 이동·방문 구조
6. 소비

영역 가중치를 적용한 결과와 모든 파생변수에 동일 가중치를 적용한 결과를
민감도 분석으로 비교한다.

## 5. Feature Engineering

### 여행 준비

- 여행상품 이용 여부와 상품 유형
- 개별 사전예약 여부
- 예약 항목 수
- 숙박, 식당, 교통, 렌터카, 관광명소, 레저·체험 등 예약 유형
- 여행지역 선택 이유
- 정보 탐색 여부
- 온라인, 지인, 공공정보, 여행사 등 정보원 대분류

설문 분기에 따라 예약 관련 개별 항목이 비결측인 사례만 예약자로 해석하지 않고,
비예약 응답 코드와 구조적 비해당을 코드북 및 값 라벨로 구분한다.

### 관광활동

A4의 세부 활동을 다음과 같은 정책 해석용 대분류로 축약한다.

- 자연·경관
- 미식
- 문화·역사
- 체험·교육
- 레저·스포츠
- 휴양·웰니스
- 쇼핑·오락
- 축제·이벤트

다음 파생변수를 생성한다.

- 활동 대분류별 참여 여부
- 전체 활동 수와 활동 대분류 수
- 주 활동 대분류
- 가족·친지·친구 방문 외 관광활동 다양성

세부 활동을 모두 독립적인 거리 변수로 넣지 않고 대분류와 활동 수를 기본으로
사용한다. 세부 다중응답은 민감도 분석에서만 사용한다.

### 동반 형태

- A6의 실제 총 일행 수
- 1인, 2인, 소규모, 대규모 구분
- 만 15세 미만 동반 여부와 아동 비중
- 반려동물 동반 여부

`D_TRA*_NUM`은 여행 일행 수가 아니라 지출비용에 포함되는 인원 수이므로 A6와
합치지 않는다. 필요하면 비용 산정 범위 변수로만 별도 사용한다.

### 체류·숙박

- 당일·숙박 여행 여부
- 숙박일수
- 가족·친지집 숙박 여부
- 상업 숙박 이용 여부
- 상업 숙박시설 유형
- 복수 숙박지역·복수 숙박유형 여부

무박 여행은 숙박시설 결측과 구분한다.

### 이동·방문 구조

- 지역간 주 이동수단
- 지역내 주 이동수단
- 자가용 의존 여부
- 대중교통 이용 여부
- 고유 방문 시군구 수
- 고유 방문 시도 수
- 단일지역·다지역 여행 여부

첫 번째 방문지를 주목적지나 실제 이동 순서로 단정하지 않는다.

### 소비

- 1인 여행비용
- 1인·1일 여행비용
- 여행지 소비액
- 숙박, 식음, 교통, 활동, 쇼핑비 비중
- 관광활동비 지출 여부
- 지역 식음·쇼핑 지출 여부

금액 변수는 분포와 극단값을 확인한 뒤 `log1p` 변환하고, 사전에 정한 분위수
기준으로 상한 처리한 결과를 민감도 분석과 함께 제시한다. 총비용, 1인 비용과
1인·1일 비용을 중복 투입하지 않고 대표 수준 변수와 구성비를 선택한다.

### 군집 입력에서 제외할 변수

다음 변수는 군집을 생성하지 않고 사후 프로파일링과 외부 검증에 사용한다.

- A9 전반적 만족도
- A10 재방문 의향
- A11 추천 의향
- A12 여행 영향
- 성별, 연령, 소득
- 거주지역과 방문지역명
- `WT_DOM`

만족도와 재방문 의향을 입력해 만족 수준이 군집을 결정하거나, 인구통계와 지역이
행동유형을 대신 구분하는 것을 방지한다.

## 6. Feature Set 비교

### F1. 핵심 행태형

- 여행 준비
- 활동 대분류
- 동반 형태
- 체류·숙박
- 이동
- 방문지역 수

해석이 가장 간단한 기준 Feature Set으로 사용한다.

### F2. 소비 확장형

F1에 다음을 추가한다.

- 1인 비용 또는 1인·1일 비용
- 소비 항목별 비중
- 관광활동비와 쇼핑비 지출 여부

정책 활용성이 높은 주 Feature Set 후보로 사용한다.

### F3. 세부 다중응답형

F2에 세분화된 활동, 예약과 정보탐색 변수를 추가한다. 변수 수가 많은 영역이
군집을 지배하는지 확인하기 위한 민감도 분석으로만 사용한다.

최종 결과는 F1과 F2 중 군집 안정성, 해석력과 정책 활용성이 더 좋은 Feature
Set을 선택한다.

## 7. 비교 방법론

DBSCAN과 다른 밀도기반 군집은 분석 대상에서 제외한다. 모든 선정여행에 정책
유형을 배정할 수 있고 공모전에서 쉽게 설명할 수 있는 다음 세 모형만 비교한다.

### M1. 원-핫 인코딩 기반 K-means

- 수치형은 로그 변환과 Robust Scaling을 적용한다.
- 범주형은 원-핫 인코딩한다.
- 이진·다중응답은 0/1로 유지한다.
- `K = 2~6`을 비교한다.
- 단순하고 재현 가능한 기준모형으로 사용한다.

### M2. Gower 거리 기반 K-medoids

- 혼합형 변수의 원래 측정 수준을 반영한 Gower 거리를 사용한다.
- 영역 가중치 적용 여부를 민감도 분석한다.
- `K = 2~6`을 비교한다.
- 각 군집의 실제 대표 여행인 medoid를 군집 설명에 사용한다.
- 해석 가능한 주 모형 후보로 사용한다.

### M3. 얕은 오토인코더 임베딩 기반 K-means

- F1과 F2의 전처리 행렬을 입력한다.
- 얕은 오토인코더로 각 선정여행의 비선형 임베딩 벡터를 학습한다.
- 임베딩에 K-means를 적용하고 `K = 2~6`을 비교한다.
- 비선형 표현이 군집 품질과 안정성을 실제로 개선하는지 검증한다.
- 복잡성 자체가 아니라 기준모형 대비 추가 가치를 채택 기준으로 삼는다.

## 8. 얕은 오토인코더 설계

### 기본 구조

```text
전처리된 d차원 입력
    → Dense 32, ReLU
    → Bottleneck 8차원
    → Dense 32, ReLU
    → 원래 입력 복원
```

- Bottleneck 후보: 4, 8, 12차원
- 주 후보: 8차원
- batch size 후보: 32, 64
- 학습·검증 분할: 80%·20%
- 조기 종료 적용
- 작은 dropout 또는 weight decay 적용
- 같은 조건에서 random seed를 바꿔 최소 5회 반복

### 입력과 손실

- 연속형: 로그 변환 후 Robust Scaling
- 범주형: 원-핫 인코딩
- 이진·다중응답: 0/1
- 구조적 비해당: 의미가 있을 때 명시적 범주로 보존
- 일반 결측: 결측률과 의미를 검토한 뒤 제한적으로 대치

연속형과 이진·범주형의 복원 성능이 한 종류의 변수에 의해 지배되지 않도록
변수 유형별 복원오차를 따로 확인한다. 필요할 때만 연속형 손실과 이진형 손실의
가중합을 사용하며 복잡한 다중 출력 구조는 추가하지 않는다.

### 과적합·불안정성 확인

- 학습·검증 재구성 오차 차이
- 변수 영역별 재구성 오차
- seed별 임베딩 K-means 군집 간 ARI
- 임베딩 차원별 실루엣과 최소 군집 크기
- 임베딩 군집을 원변수로 설명할 수 있는지 확인

재구성 오차가 낮다는 이유만으로 임베딩 모형을 채택하지 않는다. 원변수 공간에서
안정적이고 정책적으로 해석되는 군집이 만들어지는지가 최종 기준이다.

## 9. 군집 평가와 최종 선택

### 평가 지표

- 평균 실루엣 계수
- 군집별 실루엣 계수
- 최소 군집 크기와 군집 크기 불균형
- seed·부트스트랩 반복 안정성
- 원변수 프로파일의 분명함
- 정책 대응의 구체성과 군집 간 차별성

### 거리공간별 실루엣

- M1 K-means: 전처리된 유클리드 거리 실루엣
- M2 K-medoids: Gower 거리 실루엣
- M3 임베딩 K-means: 임베딩 유클리드 거리 실루엣

서로 다른 거리공간의 실루엣 절댓값만 직접 비교하지 않는다. 모든 모형의 군집
라벨을 동일한 F1 또는 F2 원변수 Gower 거리에서 다시 평가한 `공통 Gower
실루엣`을 보조 비교지표로 사용한다.

### 안정성 평가

- K-means와 오토인코더는 최소 5개 random seed로 반복한다.
- 응답자 `ID` 단위 부트스트랩으로 군집을 재추정한다.
- 반복 결과 간 Adjusted Rand Index를 계산한다.
- 군집 중심, medoid와 핵심 변수 프로파일의 재현 여부를 함께 확인한다.

### 사전 채택 조건

- 최소 군집 비중이 원칙적으로 비가중 표본의 5% 이상일 것
- 반복 결과 ARI가 실무적으로 충분한 수준인지 확인할 것
- 각 군집을 2~4개의 핵심 원변수 특성으로 설명할 수 있을 것
- 군집별 만족도·재방문·지역분포를 후속 분석할 표본이 확보될 것
- 군집별 정책 대응이 실질적으로 구분될 것

실루엣 계수는 다음의 탐색적 판단 규칙으로 사용하되 절대적인 통계 기준으로
표현하지 않는다.

- 0.25 이상: 비교적 뚜렷한 구조
- 0.15 이상 0.25 미만: 탐색적 유형으로 사용 가능하나 안정성 검증 필요
- 0.15 미만: Feature Set과 연구대상 재검토

### 오토인코더 채택 기준

다음 중 하나 이상을 충족하고 안정성과 해석성이 확보될 때 최종 모형으로 채택한다.

- 원-핫 K-means보다 공통 Gower 실루엣과 안정성이 개선된다.
- Gower K-medoids에서 드러나지 않은 정책적으로 유의미한 유형이 반복 재현된다.
- 여러 seed에서 유사한 군집 규모와 원변수 프로파일이 나타난다.
- 얕은 의사결정나무로 임베딩 군집을 원변수 기준에서 설명할 수 있다.

seed마다 결과가 크게 달라지거나, 지출액 하나가 임베딩을 지배하거나, Gower
결과를 더 복잡하게 재현할 뿐이면 강건성 분석으로만 남기고 최종 모형에서는
제외한다.

## 10. 군집 해석과 시각화

### 원변수 기반 군집 해석

- 군집별 비가중 N과 가중 구성비
- 연속형 변수의 가중 평균·중앙값
- 범주형·다중응답 변수의 가중 선택률
- 전체 대비 군집별 lift
- K-medoids medoid의 실제 여행 특성
- 깊이 3~4의 군집 예측 의사결정나무

군집명은 분석 전에 정하지 않고 결과에서 반복적으로 확인되는 핵심 특성을
바탕으로 명명한다.

### 외부 프로파일링

- A9 전반적 만족도
- A10 재방문 의향
- A11 추천 의향
- A12 여행 영향
- 성별, 연령, 소득
- 거주지역과 방문지역

이 차이는 군집의 결과 특성으로 제시하며 원인이나 정책효과로 단정하지 않는다.

### PCA

- F1·F2의 전처리 행렬에 PCA 2성분을 적용한다.
- PC1·PC2 설명분산과 주요 loading을 제시한다.
- 최종 군집 라벨을 색으로 표시한다.
- PCA는 선형 구조와 변수 방향을 설명하는 시각화로 사용한다.

### UMAP

- Gower 거리 기반 UMAP과 오토인코더 임베딩 기반 UMAP을 비교한다.
- 동일한 random state와 시각화 설정을 기록한다.
- UMAP 좌표를 최종 군집 입력으로 사용하지 않는다.
- UMAP에서 보이는 분리를 군집의 통계적 증거로 단정하지 않는다.

PCA와 UMAP은 엄밀한 XAI가 아니라 투영 시각화다. 실제 설명에는 원변수 lift,
medoid와 얕은 의사결정나무를 사용한다.

## 11. 가중치 적용

`WT_DOM`은 거리 변수, K-means 입력 또는 오토인코더 입력에 포함하지 않는다.

- 군집학습과 실루엣: 비가중 표본
- 군집별 규모와 구성비: `WT_DOM` 가중
- 군집별 만족도·지출 평균: 유효 사례에 `WT_DOM` 가중
- 지역별 군집 구성비: 선정여행 기준 `WT_DOM` 가중

가중치를 사용한 모든 표에는 비가중 N, 가중 분모, 결측 N과 추정 단위를 함께
제시한다. `sum(WT_DOM)`은 선정여행의 가중 사례 수이며 연간 고유 방문자 수로
표현하지 않는다.

## 12. 지역별 유형 분포와 정책 연결

### 방문지역 변환

- `national_travel_survey_region_code.csv`를 사용한다.
- 5자리 SPOT 코드는 `시도_코드 * 1000 + 시군구_코드`로 만든다.
- `시도_코드 + 시군구_코드` 복합키와 `many_to_one` 관계를 검증한다.
- 미매칭 코드는 별도 출력하고 임의의 인접 지역으로 대체하지 않는다.
- 현재 지역코드의 기준시점과 행정구역 명칭을 결과에 명시한다.

### 지역 집계 단위

- 여행 내 동일 시군구 반복은 한 번만 센다.
- 다지역 여행은 각 고유 방문지역에 한 번씩 연결한다.
- 결과 단위를 여행 수가 아니라 `지역 방문 건수`로 명시한다.
- 단일 방문지역 여행만 사용한 결과를 민감도 분석으로 비교한다.
- 첫 방문지를 주목적지로 임의 지정하지 않는다.
- 지역·군집 셀의 비가중 표본이 작으면 비율을 숨기거나 참고값으로 표시한다.
- 시군구 표본이 부족하면 시도 단위를 주 결과로 사용한다.

### 정책 매칭 원칙

최종 군집별 핵심 행동과 지역의 우세 유형을 연결한다. 다음은 분석 전 예시이며
실제 군집명과 정책은 결과 확인 후 결정한다.

| 군집 특성 예시 | 정책 방향 예시 |
| --- | --- |
| 가족집 숙박·낮은 관광소비 | 연고인 동반 지역체험 바우처 |
| 장기체류·활동 다양성 부족 | 체류 중 하루 지역관광 프로그램 |
| 미식·쇼핑 중심 | 지역상권 연계 소비패스 |
| 아동 동반 가족형 | 가족·친지 공동 체험상품 |
| 정보탐색·예약 부족 | 연고인이 공유하는 지역 큐레이션 |
| 활동 다양성·고소비 | 지역 앰배서더·동반자 확대 프로그램 |

국민여행조사만으로 수요 유형과 지역별 구성은 분석할 수 있으나 지역별 관광자원,
접근성, 공급 수준은 직접 설명할 수 없다. 최종 지역전략이 이 정보에 의존하면
군집 완료 후 외부 지역자료를 추가하며, 외부 지역변수를 개인 여행 군집에 억지로
투입하지 않는다.

## 13. 실행 순서

1. 분석에 필요한 변수와 값 라벨 목록을 확정한다.
2. CHECK 선정여행과 CASE 2 표본 3,819건을 재현한다.
3. 선정 슬롯 D계열과 A계열을 결합한다.
4. 설문 분기, 결측, 극단값과 다중응답 구조를 검증한다.
5. F1·F2·F3 Feature Set을 생성한다.
6. M1 원-핫 K-means를 적합한다.
7. M2 Gower K-medoids를 적합한다.
8. M3 얕은 오토인코더 임베딩 K-means를 적합한다.
9. 실루엣, 공통 Gower 실루엣, 군집 크기와 안정성을 비교한다.
10. 원변수 프로파일과 정책 해석력을 함께 평가해 최종 모형을 선정한다.
11. PCA·UMAP, lift, medoid와 얕은 의사결정나무로 군집을 설명한다.
12. 만족도, 재방문·추천 의향과 인구통계를 군집별로 비교한다.
13. 지역별 가중 군집 구성비와 표본 충분성을 확인한다.
14. 군집×지역 특성에 따른 정책 대상과 실행수단을 제안한다.

## 15. 중단·확장 판단

다음 조건이면 국민여행조사 단독 군집을 유지한다.

- 3~5개의 안정적이고 해석 가능한 유형이 도출된다.
- 군집별 정책 대상과 실행수단이 명확하게 달라진다.
- 시도 또는 일부 시군구에서 군집 구성비를 제시할 표본이 확보된다.

다음 조건이면 Feature Engineering을 재검토한다.

- 모든 모형의 실루엣이 낮고 군집 안정성이 부족하다.
- 군집이 비용 또는 특정 다중응답 영역 하나로만 구분된다.
- 군집명이 인구통계나 지역명으로만 설명된다.
- 얕은 오토인코더가 seed마다 다른 구조를 만든다.

외부 데이터는 개인 여행의 군집 분리를 인위적으로 높이기 위해 추가하지 않는다.
군집은 해석 가능하지만 지역별 실행전략이 부족할 때 인구감소지역, 관광자원,
접근성 또는 지역 관광소비 자료를 정책 매칭 단계에 추가한다.

## 16. 확정 사항

- 2025년 국민여행조사 국내여행 SAV를 사용한다.
- 분석 대상은 `CHECK == "Y"`로 선정된 CASE 2 여행이다.
- 사전 확인 기준 분석 후보는 3,819건이다.
- A계열과 CHECK 선정 슬롯의 D계열을 함께 사용한다.
- 주 비교모형은 원-핫 K-means, Gower K-medoids와 얕은 오토인코더 임베딩
  K-means다.
- DBSCAN과 다른 밀도기반 군집은 사용하지 않는다.
- 만족도, 재방문·추천 의향, 인구통계, 지역과 가중치는 군집 입력에서 제외하고
  사후 프로파일링에 사용한다.
- 실루엣 계수만으로 최종 모형을 결정하지 않고 안정성, 최소 군집 크기,
  원변수 해석력과 정책 활용성을 함께 평가한다.
- 원자료는 수정하지 않는다.

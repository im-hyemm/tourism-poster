# 연고관광 유형 1·2 분류 연구 계획

## 1. 분석 대상과 변수 정의

- 분석 단위는 응답자별 가장 최근 상세조사 여행 1건으로 한다.
- `D_TRA1_CHECK`~`D_TRA6_CHECK` 중 `"Y"`인 슬롯 번호의 최댓값을 선택한다.
- 선택 슬롯의 `D_TRA*_CASE`가 1 또는 2인 응답자만 포함하고, 유형 2를 양성 클래스(`y=1`)로 정의한다.
- A시리즈는 선택된 가장 최근 여행의 상세 응답으로 결합한다.
- 다음 변수는 모든 feature set에서 제외한다.
  - 모든 `D_TRA*_CASE`, `D_TRA*_CHECK`
  - 개별 `SA1_1`~`SA1_5`
  - `MON_EXP_*`
  - 다른 여행 슬롯의 유형 정보
  - 종속변수를 직접 재현하는 파생변수

## 2. Feature set 구성

- `F0 여행자 특성`
  - 성별, 연령, 직업, 소득, 학력, 혼인상태, 동거가구원 수, 거주 시도
  - `monthly_total_trip_count = SA1_1 + ... + SA1_5`
  - 개별 `SA1_*`는 저장하거나 모델에 전달하지 않고 합계만 사용한다.
  - 이 값은 개인의 조사대상 월 총여행횟수이며 `WT_DOM`을 곱하지 않는다.

- `F1 여행 구조`
  - 여행 월·계절, 당일·숙박 여부, 숙박일수, 여행일수
  - 평일·주말·공휴일 포함 여부, 휴가·방학 사용 여부
  - 주요 지역 간·지역 내 교통수단
  - 일행 수, 아동·반려동물 동반 여부

- `F2 여행지역`
  - 고유 방문지역 수
  - 방문 시도 17개 다중 이진 변수
  - 거주 시도와 일치하는 방문지가 하나라도 있는지 여부
  - 수도권만 방문·비수도권만 방문·혼합 방문
  - 시·구 지역만 방문·군 지역만 방문·혼합 방문
  - 첫 번째 방문지를 주목적지로 간주하지 않고 모든 `*_SPOT`을 사용한다.
  - 국민여행조사 전용 지역코드표로 `many_to_one` 결합하고 미매칭은 별도 관리한다.

- `F3 여행 준비·활동`
  - 패키지 이용, 사전예약 종류·개수, 정보원
  - 참여 활동 종류·개수와 주 활동
  - 동반자 구성 등 A1~A6 파생변수

- `F4 소비·평가`
  - 총지출, 1인당·1인 1일당 지출, 항목별 지출과 구성비
  - 전반·세부 만족도, 재방문·추천 의향

- `F5 정답 근접 변수`
  - 가족·친지·친구를 직접 언급한 여행지 선택 이유
  - 가족·친지집 숙박 여부 등 유형 2를 강하게 암시하는 변수
  - 주 모형에서는 제외하고 성능 상승 폭을 확인하는 민감도 분석에만 사용한다.

## 3. 모델링과 해석

- Feature 기여도는 동일한 Elastic Net 로지스틱 회귀로 단계적으로 비교한다.
  1. F0
  2. F0+F1
  3. F0+F1+F2
  4. F0+F1+F2+F3
  5. F0+F1+F2+F3+F4
  6. 전체+F5 민감도 분석
- 알고리즘 비교는 F5를 제외한 핵심 feature set으로 수행한다.
  - Dummy 분류기
  - Elastic Net 로지스틱 회귀
  - 깊이 3~5의 의사결정나무
  - 랜덤 포레스트
  - CatBoost
  - 로지스틱·랜덤 포레스트·CatBoost의 soft voting
  - 동일 base model의 out-of-fold stacking과 로지스틱 메타모델
- 훈련 자료의 반복 층화 5-fold 교차검증 평균 F1로 후보를 선택하고, 비슷한 성능이면 단순한 모델을 우선한다.
- 최종 해석은 로지스틱 회귀의 조정 오즈비와 최상위 트리 모델의 교차검증 SHAP을 사용한다. 앙상블은 성능 상한 확인용으로 제시한다.
- SHAP은 전체 중요도, 방향성을 나타내는 beeswarm, 상위 연속변수 dependence plot, 대표 사례 waterfall plot으로 구성하며 인과효과로 해석하지 않는다.

## 4. 가중치·평가 및 검증

- 주 모델의 학습, F1, Precision, Recall, PR-AUC 및 SHAP에는 `WT_DOM`을 적용하지 않는다.
- `WT_DOM`은 다음 모집단 EDA에만 적용한다.
  - 유형별 가중 구성비·평균·비율
  - 연간 누적 파일 전체의 총여행량: `sum(WT_DOM × monthly_total_trip_count)`
- 위 연간 총여행량은 모집단의 월별 여행량을 연간 합산한 값이며 개인별 연간 여행횟수가 아니다.
- 가중 모델은 정규화한 `WT_DOM`을 `sample_weight`로 적용한 민감도 분석으로만 수행한다.
- 불균형 대응은 임계값 조정을 우선하고 `class_weight="balanced"`를 비교한다. SMOTE는 주 분석에서 제외한다.
- 20% 층화 테스트 세트를 먼저 고정하고, 훈련 자료의 out-of-fold 예측으로 F1 최적 임계값을 결정한 뒤 테스트 세트에 한 번 적용한다.
- 테스트 결과에는 유형 2 F1, Precision, Recall, PR-AUC, 혼동행렬과 비가중 클래스 분모를 함께 제시한다.

## 5. 검증 기준과 기본 가정

- `ID`는 유일해야 하며 선택 여행은 응답자당 한 건으로 축약한다. `CHECK="Y"`가 복수이면 가장 큰 슬롯을 선택하고, Y가 없으면 제외한다.
- 대상 추출 후 선택 슬롯 번호, 유형별 비가중 표본 수, 양성 클래스 비율과 제외 건수를 다시 산출해 기록한다.
- 월간 총여행횟수는 비음수 정수이고 개별 `SA1_*` 및 target 관련 변수가 모델 행렬에 남지 않았는지 자동 검사한다.
- 지역 결합의 중복·미매칭, 다중응답 인코딩, 구조적 비해당과 일반 결측을 각각 검증한다.
- 모든 대치·인코딩·표준화·변수 선택·앙상블 메타학습은 교차검증 fold 내부에서 수행한다.
- 모델이 Dummy 기준보다 안정적으로 개선되는지와 fold별 F1 편차, F5 추가 전후 성능 차이, 가중 민감도 분석의 중요 변수 순위 일관성을 보고한다.
- 개인별 연간 여행횟수는 현재 조사자료로 만들 수 없으므로 F0에는 비가중 월간 총여행횟수를 사용한다.

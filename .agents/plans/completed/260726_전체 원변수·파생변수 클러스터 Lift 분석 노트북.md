# 전체 원변수·파생변수 클러스터 Lift 분석 노트북

## 요약

- 새 노트북을 `notebooks/04_Clustering/260726_연고관광_전체변수_클러스터_lift.ipynb`에 만들고, 대응 생성 스크립트를 `script/260726_연고관광_전체변수_클러스터_lift.py`에 둔다.
- 재학습이나 새 평가 모델 학습은 하지 않는다.
- 오토인코더 캐시가 `16차원 임베딩 + 검증 R²`만 보유하고 디코더를 저장하지 않았다는 점을 노트북에서 검증·기록한다. 새로운 재구성 성능은 계산하지 않는다.
- 공식 최종 결과인 `baseline_stratified_cluster_labeled_data.csv`를 사용한다. 동일 라벨의 `baseline_mixed_embedding`과 과거 별도 결과인 `baseline_embedding_kmeans`는 분석 대상에서 제외한다.

## 구현 내용

- 입력 품질을 검증한다.
  - 총 12,790행, ID 유일성, 양수 `WT_DOM`, 층·군집별 기존 사례 수를 확인한다.
  - 공식 선택 결과인 당일여행 2개 군집, 숙박여행 3개 군집과 일치하는지 검사한다.
- 라벨링 데이터에 남은 전체 원변수와 39개 파생변수를 lift 후보로 사용한다.
  - 제외: `ID`, `WT_DOM`, `층`, `군집`, 층 내 상수·전부 결측 변수.
  - `YEAR`는 군집의 연도 구성 변화를 확인할 수 있도록 범주형 변수로 포함한다.
- 변수 유형을 의미 기준으로 판정한다.
  - 코드북 `nominal` 또는 값 라벨이 있는 코드형 변수: 범주형.
  - 값 라벨이 없는 `scale`: 연속·계수형.
  - 파생변수는 이진형·범주형·연속형을 명시적인 사전으로 관리한다.
  - 숫자로 저장된 지역·응답 코드를 연속형 평균으로 계산하지 않는다.
- 유형별 lift를 계산한다.
  - 연속·계수형: `군집 가중평균 / 같은 층 가중평균`.
  - 범주형: 각 수준별 `군집 내 가중 비율 / 같은 층 가중 비율`.
  - 결측·비해당은 별도 수준으로 계산하되, substantive 특징 요약에서는 제외한다.
  - 분모가 0 이하인 연속형 변수는 lift를 `NaN`으로 두고 가중평균 차이와 사유를 남긴다.
  - 모든 결과에 비가중 N, 가중 분모, 결측 N, 군집값, 층 기준값, lift와 `log2(lift)`를 기록한다.
- 전체 결과와 선별 요약을 분리한다.
  - `cluster_lift_all_variables.csv`: 필터링하지 않은 전체 결과.
  - `cluster_lift_summary.csv`: 군집 셀 비가중 N 30 이상, 범주 수준의 층 내 가중 비율 1% 이상인 결과 중 `abs(log2(lift))`가 큰 특징.
  - `cluster_lift_exclusions.csv`: 키·가중치·상수·전부 결측 등 제외 사유.
- 당일·숙박 층을 분리한 lift heatmap을 만든다.
  - lift 1을 중심으로 과대표·과소대표 특징을 함께 표시한다.
  - 코드북 라벨과 범주값 라벨을 사용하고 원변수명도 병기한다.
  - 프로젝트 색상·Pretendard 글꼴을 적용해 900 DPI 이상으로 저장한다.

## 검증 및 실행

- 기존 33개 수치형 lift와 정의가 같은 행은 허용 오차 내에서 재현되는지 대조한다.
- 범주형은 군집 비중을 가중 결합했을 때 층 전체 비율이 재현되는지 검산한다.
- 연속형은 군집 가중평균을 군집 가중치로 결합했을 때 층 평균이 재현되는지 검산한다.
- 원자료와 기존 모델·결과 파일은 수정하지 않는다.
- 생성 후 tourism 가상환경에서 노트북을 처음부터 끝까지 한 번 실행해 표·그림과 셀 출력을 확인하고, 마지막 셀에서 생성 스크립트를 동기화한다.

## 가정

- 사용자가 선택한 대로 이번 노트북은 lift 확장에 집중하며, probe 모델이나 대체 오토인코더 성능지표는 포함하지 않는다.
- “전체 input”은 기존 모델링 노트북의 구조적 제외와 CASE 2 필터를 거친 라벨링 데이터에 실제로 저장된 모든 원변수를 뜻한다.
- 희소 수준도 전체 표에는 보존하되, 불안정한 고 lift가 대표 특징으로 노출되지 않도록 요약·그림에만 최소 표본 조건을 적용한다.
- `src/` 공개 API는 변경하지 않고 기존 경로·시각화·노트북 동기화 함수만 사용한다.

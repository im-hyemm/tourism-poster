# 2023~2025년 국민여행조사 사용

1. 분석이나 전처리 전에 `references/data-guide.md`를 읽는다.
2. 방문지역 코드를 사용하면 `references/region-code.md`도 읽는다.
3. 방문지역 코드 변환에는 연도별 파일 대신
   `data/raw/national_travel_survey/national_travel_survey_region_code.csv`를 사용한다.
4. 2023·2024·2025년 코드북의 지역코드를 비교한 결과, 2023→2024와 2024→2025
   모두 지역 코드·지역명 변경, 신규 지역과 소멸 지역이 없다. 비교 근거는
   `notebooks/01_Preprocess/260719_지역코드_연도비교.ipynb`의 실행 결과다.
5. 3개년 원변수 통합에는 영문자로 시작하는 공식 원변수만 사용한다. 2023년
   A문항은 2024·2025년보다 대체로 한 번호 뒤에 있으므로 `A2→A1`, `A3→A2`,
   ..., `A12→A11`처럼 문항 의미로 연결하고 같은 이름만으로 합치지 않는다.
   2023년 `A1_*`은 직접 대응이 없다. `D_TRA*_CASE`의 실제 관측 코드는 세 연도
   모두 1~5 범위다. 근거는 `260712_국민여행조사_변수정보_추출.ipynb`에 있다.
6. 2023~2025년 변수를 의미 기준으로 통합하거나 통합본을 사용할 때는
   `references/variable-harmonization.md`를 읽고 문항 이동, CHECK, D_TRA 슬롯,
   이동수단 파생과 제외 규칙을 적용한다.
7. `data/raw/national_travel_survey/` 원본은 읽기 전용으로 취급한다.
8. 변수는
   `data/raw/national_travel_survey/national_travel_survey_codebook.csv`, SAV
   메타데이터, 공식 코드북과 설문지를 순서대로 대조한다.
9. 분석 단위를 응답자, 여행, 방문지 중 하나로 명시하고 키를 기록한다.
10. 모집단 추정에는 `WT_DOM`을 적용하고 `data-guide.md`의 분석 단위별 산식을
   따른다. 가중치 적용을 위해 외부 블로그를 조회하지 않는다. 비가중 표본 수,
   가중 분모, 결측 수와 추정 단위를 함께 제시한다.
11. 설문 분기로 구조적으로 비해당인 값을 일반 결측과 구분한다.
12. 기존 노트북의 결과로 새 참고 문서를 작성할 때는 프로젝트 `AGENTS.md`가
   허용한 두 EDA만 근거로 사용한다.
13. 인구감소지역 여부를 결합하면 `use-population-decline-data`를 함께 사용한다.

## 금지 사항

- 응답자 행, 여행 슬롯, 방문지 슬롯의 가중치를 구분 없이 합산하지 않는다.
- 값 라벨을 확인하지 않고 숫자 코드를 의미로 단정하지 않는다.
- 가족·친지·친구 방문을 출생지나 법적 고향으로 확대 해석하지 않는다.
- 조사자료의 집단 차이를 정책의 인과효과로 표현하지 않는다.
- `시군구_코드`만으로 전국 시군구를 결합하지 않는다.
- 미매칭 지역을 임의의 인접 지역이나 과거 소속으로 대체하지 않는다.

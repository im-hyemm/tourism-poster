# 국민여행조사 2023~2025 방문지역 코드

## 역할과 현재 상태

- 파일:
  `data/raw/national_travel_survey/national_travel_survey_region_code.csv`
- 용도: 2023~2025년 국민여행조사의 `D_TRA*_*_SPOT` 방문지역 코드를
  시도·시군구 명칭으로 변환하는 공통 보조 코드
- 인코딩: UTF-8(BOM 없음)
- 크기: 229행, 4열
- 전체 행 중복과 결측: 없음

## 연도 비교 결과

- `notebooks/01_Preprocess/260719_지역코드_연도비교.ipynb`를 처음부터 끝까지
  실행해 2023·2024·2025년 코드북의 지역코드를 비교했다.
- 2023→2024와 2024→2025 모두 신규 코드, 소멸 코드, 명칭 변경과 코드 변경이
  각각 0건이다.
- 앞으로 방문지역 코드 변환에는 연도별 코드 파일 대신 위 공통 보조 코드를
  사용한다.

| 열            | 관측 자료형 | 의미                   |
| ------------- | ----------- | ---------------------- |
| `시도_코드`   | 정수        | 17개 시도의 2자리 코드 |
| `시도명`      | 문자열      | 시도 정식 명칭         |
| `시군구_코드` | 정수        | 시도 내부 시군구 코드  |
| `시군구명`    | 문자열      | 시군구 명칭            |

## 키와 SPOT 코드

- `시군구_코드`는 전국에서 183건 중복되므로 단독 키가 아니다.
- `시도_코드 + 시군구_코드` 복합키는 229행에서 유일하다.
- 국민여행조사의 5자리 방문지역 코드는 다음처럼 만든다.

```python
region_codes["spot_code"] = (
    region_codes["시도_코드"].astype(int) * 1000
    + region_codes["시군구_코드"].astype(int)
)
```

- 현재 생성되는 `spot_code` 범위는 11010~39020이고 모두 5자리다.
- 국민여행조사 방문지역과 결합할 때 `many_to_one` 관계를 검증하고 미매칭
  코드를 별도 표로 남긴다.

## 행정구역 주의사항

- 이 파일은 독립적인 범용 행정구역 코드가 아니라 국민여행조사 2023~2025의
  방문지역 값을 해석하기 위한 보조 자료다.
- `강원도`, `전라북도`처럼 특별자치도 개칭 이전 명칭을 사용한다.
- `군위군`은 `경상북도`에 들어 있으며 대구광역시 편입이 반영되지 않았다.
- 다른 지역 자료와 이름으로 결합할 때 명칭 정규화표와 기준 시점을 명시한다.
- 원본을 고치지 말고 필요한 정규화 열을 전처리 결과에 추가한다.
- 미매칭 지역을 임의의 인접 지역이나 과거 소속으로 대체하지 않는다.

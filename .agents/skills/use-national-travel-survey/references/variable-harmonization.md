# 2023~2025년 국민여행조사 변수 조화 기준

## 적용 범위

이 문서는 2023~2025년 국민여행조사 국내여행 SAV를 응답자·조사회차 1행의
wide 형식으로 통합할 때 적용한다. 분석 단위는 응답자·조사회차이며 기본 키는
`YEAR + ID`다. 원본 SAV는 읽기 전용으로 유지한다.

## 해석 근거의 우선순위

변수의 의미가 충돌하면 다음 순서로 판단한다.

1. SAV의 실제 변수명, 변수 라벨, 값 라벨과 관측값
2. 공식 유저가이드, 코드북과 설문지
3. 사용자가 확인한 조사·전처리 규칙
4. 프로젝트 변수표와 허용된 EDA 결과

정규식과 변수명 유사도는 후보 탐색에만 사용한다. 최종 통합 여부와 변환은
명시적인 규칙으로 결정하고 변수 사전에 기록한다.

## 사용자 검증 변수 대응표

`data/raw/national_travel_survey/2023_2025_국민여행조사_코드북_대응변수_및_처리방식.csv`는
사용자가 2023년 코드북을 변수 하나씩 검토하며 작성한 열별 처리 방식이다. 이 문서의
일반 규칙과 CSV의 내용이 충돌하면 CSV를 따른다(해석 근거 우선순위 3번). CSV에서
`stretegy`(처리 방식)가 채워진 행은 이 문서의 일반 규칙으로 대부분 설명되며,
CSV 원문을 열 단위로 그대로 확인해야 할 때는 [[2023-codebook-appendix]]를 연다.
그 문서에 없는 열은 `stretegy`가 비어 있던 공통 변수다.

- 열 구성: `col_name`(2023년 원변수명), `description`(2023년 라벨), `value_labels`
  (2023년 값 라벨), `stretegy`(처리 방식). `stretegy`가 비어 있으면 추가 처리 없이
  공통 변수로 취급한다.
- `stretegy` 값의 유형
    - 다른 변수명 하나만 적힌 경우(예: `A1A`, `A9C_1`): 해당 이름으로 단순 이동
      (rename)한다.
    - `삭제` 또는 `대응되는 변수 없음. 제거`: 통합본에서 제거한다.
    - `T/F로 전환`: 항목별 존재 여부를 불리언으로 바꿔 포함한다.
    - 그 외 서술형 텍스트: 연도별 코드 재매핑, 슬롯 결합 같은 구체적 규칙을 설명한다.
      노트북 구현 시 그대로 따른다.
- 이 CSV는 2023년 코드북 변수만 순회한다. 2024·2025년 전용 신규 변수의 처리는 이
  표에 나타나지 않으므로 기존 원칙(연도 전용 신규 문항은 제외)을 따른다.

## 접두사와 분석 단위

- `A`: A계열 관광행태 문항이다. 2023년 문항 번호는 2024·2025년보다 대체로
  하나 뒤에 있으므로 질문 의미를 기준으로 이동한다.
- `D`: 여행·방문지와 관련된 원변수다.
- `D_TRA{k}`: `k`번째 개별 여행 슬롯이다. 분석 키는 `YEAR + ID + TRIP_NO`다.
- `N`: 같은 질문의 1인 기준 비용이다. 비용 원액과 합치지 않는다.
- `P`: 비용 포함 또는 공동 이용 인원 수다. 비용과 합치지 않는다.
- `T`: 기타 서술형 텍스트다. 범주형 응답과 합치지 않는다.
- `M`: 동반자 등 반복응답이다. 단일응답과 합치지 않는다.

`NA*`, `PA*`처럼 A문항에 딸린 접두사도 2023년 문항 번호 이동을 함께 적용한다.
비용 원액, 총액, 1인 비용, 인원 수와 텍스트는 별도 변수로 보존한다.

## D_TRA 슬롯과 여행 존재

- 여행 슬롯은 관측된 최대 6개를 사용한다. 2023년과 2025년은 1~6차,
  2024년은 1~5차까지 수집되었다.
- 2024년 `D_TRA6_*`는 통합 스키마에는 포함하지만 모두 `NA`로 두고 변수
  사전에 `available=False`, `treatment=not_collected`로 기록한다.
- 방문지 반복 슬롯은 확인된 최대 17개까지 보존한다.
- 여행 존재는 `D_TRA{k}_CASE`의 비결측으로 판단한다. 특정 CASE 코드 집합으로
  여행을 제외하지 않는다.
- 현재 SAV에서 CASE의 실제 관측 범위는 세 연도 모두 1~5다. 공식 값 라벨에
  더 넓은 코드가 정의되어 있어도 관측되지 않은 코드를 임의로 삭제하거나
  다른 의미로 바꾸지 않는다.

## CHECK와 A계열 응답 대상 여행

- `D_TRA{k}_CHECK == "Y"`는 해당 슬롯이 A계열 본설문 응답 대상 여행이라는
  뜻이다.
- 응답자별 `Y` 슬롯은 최대 1개이며, A계열 핵심 문항의 응답 여부와 일치한다.
- 빈 문자열은 A계열 비응답을 뜻하며 여행 없음과 같지 않다. CASE 3 또는 5와
  같이 CHECK가 비어 있어도 날짜·방문지·CASE가 있는 실제 여행이 존재한다.
- 따라서 CHECK는 여행 존재 판정에 사용하지 않고, 2023년 A계열 응답을 특정
  여행 슬롯에 연결할 때 사용한다.

공식 문서의 선정 여행 설명과 프로젝트에서 과거에 가정했던 “가장 최근 여행”
규칙이 충돌했으나, SAV의 CHECK와 A계열 응답 패턴을 검산한 결과 CHECK가 가리키는
본설문 대상 여행을 적용한다. 날짜로 최근 여행을 다시 추정하지 않는다.

## 2023년 이동수단 파생

통합 변수 `D_TRA{k}_B7_1~3`은 지역내·지역간을 구분하지 않는 여행 슬롯의 주요
이동 교통수단 1~3순위다.

- 2023년: `A1_1~A1_3` 값을 CHECK가 `Y`인 여행 슬롯의 `D_TRA{k}_B7_1~3`에
  그대로 할당한다. CHECK가 `Y`가 아닌 나머지 모든 여행 슬롯은 `B7_1~3`을
  비워둔다(`NA`).
- 2024·2025년: 지역간 `D_TRA{k}_B7A_1~3`과 지역내 `D_TRA{k}_B7B_1~3` 값을
  합쳐 1~3순위를 다시 계산한 뒤, 그 결과를 `D_TRA{k}_B7_1~3`에 할당한다.

2023년 `A1_*`의 코드 `11`은 `기타`지만 2024·2025년 B7A/B7B의 코드 `11`은
`도보`, 코드 `12`는 `기타`다. 의미를 맞추기 위해 2023년 `11=기타`를 통합 코드
`12=기타`로 바꾼 뒤 `B7_1~3`에 할당한다. 검증은 이 `11→12` 변환 후 값과
비교한다.

## A계열 번호·범주 변화

- 2023년 `A2→A1`, `A3→A2`, ..., `A12→A11`처럼 2024·2025년 질문 의미를
  기준으로 이름을 이동한다. `NA*`, `PA*`에도 같은 문항 이동을 적용한다. 이
  번호 이동은 지출 세부 항목(Q8→Q7, Q9→Q8)과 만족도 세부 항목(Q10→Q9)의
  `A`, `NA`, `PA` 접두사 조합 전체에도 동일하게 적용된다(예: `A9C_1→A8C_1`,
  `NA9G_5→NA8G_5`). 열 단위 정확한 대응은 [[2023-codebook-appendix]]를 따른다.
- 2023년 이동수단 `A1_*`은 B7 파생에만 사용하며 2024·2025년 여행사 상품
  문항 `A1`과 합치지 않는다.
- **여행사 상품 구매**: 2023년 `A2`(구매여부: 예/아니오)와 `A2B`(패키지
  종류: 전체/부분)를 2024·2025년 `A1`의 3범주(`1=전체 패키지`,
  `2=부분 패키지`, `3=구매 안함`)로 합친다. `A2=2(아니오)`는 통합 코드 `3`,
  `A2B=1`은 `1`, `A2B=2`는 `2`로 대응한다. 이진(0/1) 조화는 사용하지 않는다.
  `A2A`(구매시기)는 `A1A`로 단순 이동한다. `A2BA_1~5`(부분패키지 세부)는
  대응 변수가 없어 삭제한다.
- **사전예약사항**(2023 `A3_1~7, A3_10~11` → 통합 `A2_1~11`): 과거에는
  범주 체계 차이로 제외했으나, 항목별 존재 여부를 `T/F`로 전환해 포함한다.
  2024·2025년 `A2_1~11`도 동일한 항목 인덱스로 `T/F` 전환한다.
- **여행지에서의 활동**(2023 `A5_1~21`, `A5A` → 통합 `A4_1~21`, `A4A`):
  항목별 `T/F` 전환으로 포함한다. `A5A→A4A`는 단순 이동이다. 2025년 코드 16의
  의미가 확대된 문제는 `T/F` 전환 자체에는 영향을 주지 않지만, 카테고리
  단위로 연도를 비교할 때는 유의한다.
- **정보 획득 경로**(2023 `A6_1~3` → 통합 `A5_1~3`)는 단순 이동이다.
  **참고한 인터넷 사이트**(2023 `A6A_1~3` → 통합 `A5A_1~3`)는 범주 수가
  달라(2023년 9개, 2024·2025년 11개) 값을 재매핑한다: 2024·2025년 코드
  `1+2+3→1`, `4→2`, `5→3`, `6→4`, `7→9`, `8→6`, `9→7`, `10→8`, `11→9`. 이
  변환 후 2023년 코드 `5`(여행 관련 블로그)는 순위에 따라 다시 `_1`은 `9`,
  `_2`는 `10`, `_3`은 `11`로 흡수된다(원문 그대로이며 값 자체가 9를 넘는
  이유는 확인되지 않았으니 노트북 구현 전 사용자에게 재확인한다). 정확한
  문구는 [[2023-codebook-appendix]]의 `A6A_1~3` 항목을 그대로 따른다.
- **동반자 유형**(2023 `A7B_1~7` → 통합 `A6B_1~7`)은 2024·2025년 12범주를
  2023년 7범주로 통합한 뒤 항목별 `T/F`로 전환한다: `A6B_1,2,4,6→A7B_1`,
  `A6B_3,5→A7B_2`, `A6B_7,8→A7B_3`, `A6B_9→A7B_4`, `A6B_10→A7B_5`,
  `A6B_11→A7B_6`, `A6B_12→A7B_7`.
- 값 범주가 확대되거나 의미가 달라진 그 외 변수는 공통 의미로 안전하게
  재코딩할 수 있을 때만 포함한다.
- 일반적인 연도 전용 신규 문항은 3개년 비교 중심 통합본에서 제외한다.
  D_TRA 최대 슬롯, 2023년 이동수단 파생, 위에 명시한 T/F 전환·재매핑 항목은
  명시적인 예외다.

## 삭제 변수와 비여행이유 코드 통합

- 다음 변수는 대응되는 변수가 없거나 신뢰할 수 없어 통합본에서 삭제한다:
  `SA1_6`, `MON_EXP_6`(1년 이하 해외여행 경험 — 국내여행 SAV 범위와
  무관하며, "D*TRA 슬롯과 여행 존재"에서 다루는 국내 6차 여행 슬롯
  `D_TRA6*\*`와 혼동하지 않는다), `A2BA_1~5`(부분패키지 세부),
`TB9_11`(비여행이유 기타 텍스트), `DQ4A~DQ4CA`(가구주와의 관계·성별·
  학력·학력 이수 여부).
- **비여행이유**(2023 `B9_1~3` ↔ 2024·2025 `ZQ1_1~3`)는 코드를 다음과 같이
  합친다: 2024·2025년 코드 `11`(최근에 여행을 다녀와서)과 `12`(기타)는
  2023년 코드 `11`(기타)로 합치고, 2023년 코드 `21`(코로나19)도 2023년
  코드 `11`(기타)로 합친다.

## 결측과 비교 상태

- 연도 미수집, 설문 분기의 구조적 비해당, 일반 결측과 `-1` 파생 코드를
  구분한다.
- `comparison_status`는 `direct`, `harmonized`, `derived_with_assumption`,
  `partially_available` 중 하나를 사용한다.
- 통합 변수 사전은 통합 CSV의 열과 같은 순서로 1:1 대응하며 연도별 원변수명,
  원라벨, 값 라벨, 존재 여부와 변환 규칙을 포함한다.
- `WT_DOM`은 연도별 모집단 추정에 사용하며 세 연도 값을 3개년 고유 인구
  가중치처럼 단순 합산하지 않는다.

# 인구감소지역 목록 스키마

## 원본과 현재 상태

- 파일: `data/raw/pop_decline_danger/pop_decline_danger_region.csv`
- 인코딩: UTF-8 BOM
- 크기: 89행, 2열
- 전체 행 중복과 결측: 없음

| 열        | 자료형 | 의미          |
| --------- | ------ | ------------- |
| `sido`    | 문자열 | 시도 약칭     |
| `sigungu` | 문자열 | 지정 시군구명 |

시도 약칭은 부산, 대구, 인천, 경기, 강원, 충북, 충남, 전북, 전남, 경북,
경남의 11종이다. 이 파일에는 행정구역 코드, 지정 연도, 지정 사유, 위험 점수가
없다.

## 사용 범위

- 목록에 존재하면 인구감소지역인 이진 플래그를 만드는 용도로 사용한다.
- 89개 행 전체가 지정지역 목록이라는 전제 외에 위험도나 순위를 만들지 않는다.
- 법적 정의와 기준 시점이 필요한 글에서는 행정안전부 원출처를 별도로 확인한다.

## 지역코드 결합

1. `use-national-travel-survey`의 `references/region-code.md`를 먼저 읽는다.
2. `sido` 약칭을 지역코드 파일의 명칭 체계로 명시적으로 변환한다.
3. 변환된 시도명과 시군구명을 함께 키로 사용한다.
4. `many_to_one` 또는 `one_to_one` 관계와 미매칭 목록을 확인한다.

현재 파일끼리 명칭을 정규화해 결합하면 89개 중 88개가 일치한다. 유일한
미매칭은 `대구-군위군`이다. 인구감소지역 목록은 대구 편입 이후 상태지만
국민여행조사 전용 지역코드는 군위군을 경상북도로 분류하기 때문이다. 기준 시점을 정해
명시적으로 보정하기 전까지 이 행을 자동 수정하지 않는다.

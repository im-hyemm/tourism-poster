# 시군구 경계 지도 사용

1. 결합·시각화 전에 `references/schema.md`를 읽는다.
2. `전국_시군구_2025_2Q.geojson`은 `SIGUNGU_CD`, `SIGUNGU_NM`만 있고 시도명이
   없다. `SIGUNGU_CD` 앞 2자리로 시도명을 만든다. 매핑표는
   `references/schema.md`에 있다.
3. 결합 대상 표가 도시 단위로 집계되어 있으면(예: 수원시, 성남시처럼 구
   분할 없이 하나의 행) `SIGUNGU_NM`을 공백으로 나눠 첫 토큰으로 묶어
   `dissolve`한 뒤 결합한다. 대상 표가 구 단위이면 `dissolve`하지 않는다.
4. 시도명·시군구명 복합키로 결합한다. `SIGUNGU_CD`나 시군구명 단독으로
   결합하지 않는다. 같은 시군구명이 여러 시도에 있다
   (중구·동구·서구·남구·북구는 5개 안팎, 고성군은 강원·경남 2곳).
5. 결합 전후 행 수를 비교하고 `outer` 병합과 `indicator=True` 등으로
   미매칭 여부를 반드시 확인한다. 미매칭이 있으면 원인을 먼저 규명한다.
6. 결합 대상 표에 따라 아래 두 알려진 명칭 불일치를 점검하고 필요한 쪽만
   보정한다. 두 사례 모두 `references/schema.md`에 상세히 있다.
   - 군위군: 2023년 대구광역시 편입. geojson은 이미 대구 코드(`22520`)로
     분류하지만, 국민여행조사 전용 지역코드처럼 편입 이전 명칭(경상북도)을
     쓰는 표가 있다.
   - 인천 남구/미추홀구: 2018년 개칭. geojson은 새 이름(미추홀구)을 쓰지만
     옛 이름(남구)을 쓰는 표가 있다.
7. 보정은 노트북·스크립트 안에서 결합 직전에 코드로 수행하고, geojson
   원본이나 결합 대상 원본 파일을 고치지 않는다.
8. 단계구분도 자체의 색상·제목·범례 스타일은 `visualize-tourism-results`를
   따른다. 여러 범주(군집 등)를 비교하는 지도 세트는 `PALETTE` 색을
   범주별로 고정 배정하고, 같은 범주를 그리는 다른 지도(구성비 지도와
   규모 지도 등)에서도 같은 색을 재사용한다.
9. 좌표계는 원본 EPSG:4326을 그대로 써도 되지만, 면적 기반 정밀 계산이
   필요하면 등적 좌표계로 재투영한다.

## 금지 사항

- `SIGUNGU_CD`나 시군구명만으로 전국 시군구를 결합하지 않는다.
- 미매칭 지역을 지도에서 조용히 제외하지 않는다. 결합 전후 행 수와
  미매칭 목록을 결과에 남긴다.
- 군위군·인천 남구/미추홀구 보정을 다른 지역에도 통하는 일반 규칙으로
  확장하지 않는다. 두 사례는 각각의 행정구역 변경 이력에 따른 예외다.
- `data/raw/sigungu_map`의 원본 geojson을 수정하거나 덮어쓰지 않는다.

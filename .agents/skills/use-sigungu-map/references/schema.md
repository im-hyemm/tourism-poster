# 시군구 경계 geojson 스키마

## 원본과 현재 상태

- 파일: `data/raw/sigungu_map/전국_시군구_2025_2Q.geojson`
- 기준 시점: 2025년 2분기(`BASE_DATE`가 `20250630`으로 전체 동일)
- 좌표계: EPSG:4326(위경도)
- 크기: 252개 피처, 속성은 `BASE_DATE`, `SIGUNGU_CD`, `SIGUNGU_NM` 3개뿐
- 시도명 속성이 없다. 시도 구분은 `SIGUNGU_CD`로 직접 만들어야 한다.

| 열           | 자료형 | 의미                          |
| ------------ | ------ | ----------------------------- |
| `BASE_DATE`  | 문자열 | 경계 기준일(YYYYMMDD), 전체 동일값 |
| `SIGUNGU_CD` | 문자열 | 5자리 시군구 코드              |
| `SIGUNGU_NM` | 문자열 | 시군구명(구 단위 도시는 "OO시 OO구" 형태) |

## SIGUNGU_CD 앞 2자리 → 시도명

`region_trip_feature.csv`, 국민여행조사 전용 지역코드 등 이 프로젝트의 표가
쓰는 시도 정식 명칭과 일치시키려면 다음 매핑을 쓴다.

```python
PROVINCE_BY_CODE_PREFIX = {
    "11": "서울특별시", "21": "부산광역시", "22": "대구광역시", "23": "인천광역시",
    "24": "광주광역시", "25": "대전광역시", "26": "울산광역시", "29": "세종특별자치시",
    "31": "경기도", "32": "강원도", "33": "충청북도", "34": "충청남도",
    "35": "전라북도", "36": "전라남도", "37": "경상북도", "38": "경상남도",
    "39": "제주특별자치도",
}
sigungu_gdf["시도명"] = sigungu_gdf["SIGUNGU_CD"].str[:2].map(PROVINCE_BY_CODE_PREFIX)
```

`강원도`, `전라북도`처럼 특별자치도 개칭 이전 명칭을 쓴다. 국민여행조사 전용
지역코드(`use-national-travel-survey`의 `references/region-code.md`)와 표기가
같다.

## 구 단위로 나뉜 도시(dissolve 대상)

다음 12개 시는 `SIGUNGU_NM`이 "OO시 OO구" 형태로 여러 행에 나뉘어 있다.
결합 대상 표가 도시 단위 하나의 행으로 집계돼 있으면(예:
`region_trip_feature.csv`는 229행으로 이 12개 시를 각각 한 행으로 집계)
공백 앞 토큰으로 묶어 `dissolve`해야 행 수가 맞는다.

| 시     | 포함 구 수 | 구 목록                                             |
| ------ | ---------- | ---------------------------------------------------- |
| 수원시 | 4          | 장안구·권선구·팔달구·영통구                          |
| 성남시 | 3          | 수정구·중원구·분당구                                 |
| 안양시 | 2          | 만안구·동안구                                        |
| 부천시 | 3          | 원미구·소사구·오정구                                 |
| 안산시 | 2          | 상록구·단원구                                        |
| 고양시 | 3          | 덕양구·일산동구·일산서구                             |
| 용인시 | 3          | 처인구·기흥구·수지구                                 |
| 청주시 | 4          | 상당구·서원구·흥덕구·청원구                          |
| 천안시 | 2          | 동남구·서북구                                        |
| 전주시 | 2          | 완산구·덕진구                                        |
| 포항시 | 2          | 남구·북구                                            |
| 창원시 | 5          | 의창구·성산구·마산합포구·마산회원구·진해구           |

나머지 시군구(세종시 포함)는 공백 없이 도시 단위 그대로 한 행이다. 일반화한
dissolve 키는 다음처럼 만든다.

```python
# "수원시 장안구" -> "수원시", "군위군" -> "군위군"(공백 없으면 그대로 유지)
sigungu_gdf["시군구명"] = sigungu_gdf["SIGUNGU_NM"].str.split(" ").str[0]
city_level_gdf = sigungu_gdf.dissolve(by=["시도명", "시군구명"], as_index=False)
```

이 dissolve를 거치면 252개 피처가 229개 도시 단위 행으로 줄어든다
(35개 구 행이 12개 도시 행으로 합쳐져 23행 감소).

구 단위로 결합해야 하는 표(예: 구별로 세분화된 통계)라면 이 dissolve를
하지 않고 `SIGUNGU_NM`을 공백 포함 그대로 키로 쓴다.

## 알려진 명칭 불일치

### 군위군

- geojson은 군위군을 이미 대구광역시 코드(`22520`)로 분류한다(2023년 7월
  대구 편입 반영).
- 국민여행조사 전용 지역코드, `region_trip_feature.csv` 등 이 프로젝트의
  여러 표는 편입 이전 명칭대로 군위군을 경상북도에 둔다.
- `use-population-decline-data`의 `references/schema.md`도 같은 불일치를
  기록하고 있다(인구감소지역 목록 결합 시 유일한 미매칭 사례).
- 결합 대상 표가 경상북도로 표기하면, 결합 직전 해당 표에서만
  `군위군`의 시도명을 `대구광역시`로 바꾼다. geojson 쪽은 이미 맞으므로
  고치지 않는다.

### 인천 남구 / 미추홀구

- 인천광역시 남구는 2018년 미추홀구로 개칭됐다.
- geojson은 새 이름 미추홀구를 쓴다.
- `region_trip_feature.csv` 등 국민여행조사 계열 표는 옛 이름 남구를 그대로
  쓴다.
- 결합 대상 표가 옛 이름을 쓰면, geojson 쪽 미추홀구를 결합 직전에만
  남구로 바꿔서 맞춘다(반대로 대상 표가 새 이름을 쓰면 geojson은 그대로
  두고 대상 표를 고치지 않는다).

## 결합 검증

두 사례를 모두 보정하면 dissolve한 229개 도시 단위 geojson 행과
`region_trip_feature.csv`의 229행이 시도명·시군구명 복합키로 완전히
일치한다(교차 검증 완료, 미매칭 0건). 다른 표와 결합할 때도 반드시
`outer` 병합과 `indicator=True`로 미매칭 여부를 직접 확인하고, 미매칭이
있으면 두 사례 외의 새로운 명칭 변경이 있는지부터 의심한다.

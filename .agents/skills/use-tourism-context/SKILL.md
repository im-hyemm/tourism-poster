# 관광 공모전 문맥 사용

1. 공모전 형식과 평가 기준을 판단할 때 `references/contest-brief.md`를 읽는다.
2. 연고 방문 기획의 범위와 용어를 판단할 때 `references/project-purpose.md`를 읽는다.
3. 보고서나 포스터의 전달 구조를 설계할 때 `references/winner-patterns.md`를 읽는다.
4. 원문 확인이 필요하면 각 참조 문서에 적힌 프로젝트 원본을 직접 확인한다.
5. 공모전 요건, 기획 주장, 수상작에서 관찰한 패턴을 서로 구분해 작성한다.
6. 데이터 구조·변수·가중치·결합 규칙은 해당 데이터 스킬에 맡긴다.

## 적용 원칙

- 수상작의 주제나 문장을 복제하지 말고 전달 방식만 참고한다.
- 기획 메모의 정책 주장을 검증된 분석 결과처럼 표현하지 않는다.
- 외부 자료를 인용하면 출처를 남기고, 투어고인사이트 인용 여부를 구분한다.
- 상세 분석 전략이나 특정 통계기법을 이 스킬에 추가하지 않는다.

# 연고 방문 프로젝트 목적

## 원본

- `docs/note/연고관광_purpose.md`

## 문제 정의

지역소멸 대응은 정주인구뿐 아니라 지역에 체류하고 반복적으로 관계를 맺는
생활인구·관계인구를 필요로 한다. 기존 관광정책은 신규 방문객 유치에 집중해
비용이 크고, 일회성 방문이 지역의 지속적인 관계나 소비로 이어지지 않는 한계가
있다는 것이 이 기획의 출발점이다.

## 핵심 착안점

가족·친지·친구를 만나기 위한 방문자는 이미 특정 지역과 관계가 있고 반복해서
방문할 가능성이 있다. 이 기획은 새로운 관계를 만드는 정책을 대체하지 않고,
이미 존재하는 관계를 관광활동과 지역소비로 심화하는 보완 축을 제안한다.

## 용어 경계

- `고향`은 정책의 정서적 슬로건과 브랜드다.
- 데이터의 실제 분석 대상은 국민여행조사의 가족·친지·친구 방문인
  `연고 기반 방문`이다.
- 연고 기반 방문은 출생지, 법적 고향, 관계의 지속기간을 직접 식별하지 않는다.
- 국민여행조사 여행유형 2는 관광·휴양 활동을 포함한 가족·친지·친구 방문,
  여행유형 3은 관광·휴양 활동이 없는 단순 가족·친지·친구 방문이다.

## 정책 목표

이미 지역을 방문하는 연고 방문객을 지역에서 소비하고 체험하는 방문객으로,
나아가 외지 동반자를 데려오는 방문객으로 전환한다. 기획 메모는 `고향 바우처
+ SNS 연계`를 초기 정책 모델로 제안하지만, 구체적인 효과와 규모는 분석 결과로
검증해야 한다.

## 표현 원칙

- 연고 방문객이 곧 관계인구라는 단정 대신 관계인구로 발전할 잠재력이 있다고
  표현한다.
- 지역소비 부족, 반복 방문, 동반자 확대는 데이터로 확인한 범위만 주장한다.
- 기획 배경의 정책·예산·법률 사실은 최종 보고서 작성 시 최신 원출처로 재검증한다.

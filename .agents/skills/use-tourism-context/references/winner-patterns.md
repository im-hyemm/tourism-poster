# 과거 수상작 구성 패턴

## 검토 원본

`docs/winner/`의 대상 1편, 최우수상 1편, 우수상 2편, 장려상 2편을 검토했다.
이 문서는 수상작의 정답이나 재사용 가능한 결론이 아니라 전달 구조에서 관찰한
패턴을 기록한다.

## 작품별 관찰

- 대상 `옹고집쌈밥`: 미활용 폐교라는 구체적 지역문제에서 출발해 여러 공공자료로
  지역을 단계적으로 압축하고, 입지 점수와 MCLP를 거쳐 실제 폐교별 관광시설
  아이디어까지 연결한다.
- 최우수상 `너도나도전라도`: 외국인 유학생이라는 명확한 대상을 정하고 여러 연도
  외래관광객조사를 정합화한 뒤 군집과 리뷰 텍스트를 테마 관광, 수도권 연계 상품,
  미식 프로그램으로 번역한다.
- 우수상 `성차박`: 차박 수요와 지역 관광을 연결하고 국민여행조사, 접근성,
  문화·여가시설, 온라인 텍스트를 조합해 도입지와 테마를 선정한 뒤 고객 여정과
  지역별 아이디어를 제시한다.
- 우수상 `전지적관광시점`: 관광 활성화가 필요한 지역을 공간적으로 찾고 지출·만족
  관계를 분류한 뒤 지역 특성에 맞춘 한방·웰니스 코스와 긍정·부정 요인 개선책으로
  연결한다.
- 장려상 `NEST`: 관계인구 후보를 설문 조건으로 좁히고 EDA, 계층 군집, 지역
  필터링을 거쳐 3개 시범지역을 선정한다. NEST 약어를 자연·체험·체류·이동의
  서비스 묶음으로 풀어 운영 방식과 한계까지 제시한다.
- 장려상 `에코모드ON`: 국민여행조사와 생태관광지 자료를 결합해 방문 의향을
  설명하고 군집별 후보지역을 선정한 뒤 포인트, 로드맵, 교통 패스, 그린리터 같은
  하나의 서비스 경험으로 구성한다.

## 공통 전달 구조

1. 사회문제와 관광문제를 한 문장으로 연결한다.
2. 정책 대상 또는 대상 지역을 명확히 한정한다.
3. 데이터가 각 분석 단계에서 맡는 역할을 도식으로 먼저 보여준다.
4. 전국 또는 전체 표본에서 후보를 단계적으로 압축한다.
5. 분석 결과를 지역명, 대상 집단, 관광자원과 대응시킨다.
6. 마지막에는 프로그램, 코스, 서비스 화면, 운영 방식처럼 실행 모습을 보여준다.
7. 기대효과를 관광객과 지역 또는 행정의 관점으로 나누어 설명한다.

## 참고 시 주의사항

- 복잡한 기법의 수보다 문제 정의와 결과-정책 연결이 더 선명하게 보인다.
- 지도, 순위, 군집명은 선정 기준과 분모를 함께 제시해야 설득력이 생긴다.
- 수상작의 모델명, 서비스명, 문장, 화면 구성은 복제하지 않는다.
- 수상작에서 사용한 분석법을 현재 데이터에 적합성 검토 없이 가져오지 않는다.

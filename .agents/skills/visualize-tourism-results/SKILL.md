# 관광 분석 결과 시각화

1. 그래프를 만들기 전에 `references/visual-style.md`를 읽는다.
2. 분석 질문과 비교 대상을 한 문장으로 정한 뒤 가장 단순한 차트를 고른다.
3. `src.visualization.apply_plot_style()`을 호출하고 `COLORS` 또는 `PALETTE`의
   명시적 색상만 사용한다.
4. 제목은 중립적으로 작성하고 단위, 기간, 분모, 표본 수, 가중 여부가 해석에
   필요하면 부제나 주석에 표시한다.
5. 색상만으로 집단을 구분하지 말고 직접 레이블, 선 모양, 마커 또는 정렬을
   함께 사용한다.
6. 최종 그림은 `outputs/{노트북 파일명}/figures/`에 900 DPI 이상으로 저장한다.
7. 전달할 실제 이미지에서 한글 깨짐, 잘림, 겹침, 범례 중복과 축 왜곡을 확인한다.

## 선택 원칙

- 범주 비교에는 정렬된 막대나 점 그래프를 우선한다.
- 시간 흐름은 관측점이 충분할 때만 선 그래프로 표현한다.
- 정확한 값 조회가 목적이면 표를 사용한다.
- 구성비는 누적 막대를 우선하고 원형 그래프는 소수 범주에만 제한한다.
- 일반적인 절대 크기 막대그래프는 0에서 시작한다.
- 하나의 계열에는 한 비중립색을 기본으로 사용하고, 다범주 팔레트는 최대
  5개 색상으로 제한한다.
- 초록·빨강만으로 긍정과 부정을 구분하지 않는다.

# 관광데이터 시각화 스타일

## 공통 구현

모든 Matplotlib·Seaborn 그림은 먼저 다음 설정을 적용한다.

```python
from src.visualization import COLORS, PALETTE, apply_plot_style

apply_plot_style()
```

글꼴은 프로젝트의 `font/Pretendard-1.3.9/public/static/`에 있는 Regular,
Medium, SemiBold, Bold OTF를 사용한다. 시스템에 설치된 글꼴에 의존하지 않는다.

## 색상 의미

| 이름 | HEX | 기본 용도 |
| --- | --- | --- |
| `primary` | `#2F5D8C` | 주 분석 집단, 핵심 계열 |
| `secondary` | `#2A9D8F` | 비교 집단, 보조 계열 |
| `accent` | `#E76F51` | 정책적으로 강조할 값 |
| `highlight` | `#E9C46A` | 주의가 필요한 보조 강조 |
| `neutral` | `#6B7280` | 기준값, 기타 집단, 축 |
| `negative` | `#C44E52` | 위험·감소·부정 상태 |
| `background` | `#FAFAF8` | 그림과 축 배경 |

- 동일 개념은 모든 그림에서 같은 색을 사용한다.
- 한 계열 그래프는 `primary` 한 색과 중립색을 우선한다.
- 두 집단 비교는 비중립색 두 개를 넘기지 않는다.
- 범주 정체성이 중요한 경우에만 `PALETTE`를 최대 5개까지 사용한다.
- 색만으로 구분하지 않고 직접 레이블, 마커, 선 모양, 명암을 병행한다.

## 글자와 레이아웃

- 기본 본문·눈금: 11pt
- 축 제목: 13pt
- 그림 전체 제목: 16pt
- 범례: 10pt
- 제목은 무엇을 그렸는지 중립적으로 적는다.
- 단위, 기간, 분석 단위, 가중 여부, 분모·표본 수는 필요한 위치에 표시한다.
- 긴 범주명에는 가로 막대그래프와 충분한 왼쪽 여백을 사용한다.
- 위·오른쪽 테두리는 숨기고 격자는 비교를 돕는 축에만 약하게 사용한다.

## 차트 선택

- 시간 흐름: 관측점이 충분한 선 그래프
- 범주 비교와 순위: 정렬한 막대 또는 점 그래프
- 구성비: 누적 막대, 범주가 매우 적을 때만 원형 그래프
- 분포: 히스토그램 또는 집단 비교용 상자그림
- 두 연속변수 관계: 충분한 관측치가 있는 산점도
- 정확한 값 조회: 간결한 표

절대 크기를 비교하는 막대는 0에서 시작한다. 축을 좁혀야 하는 변화량 그래프는
정확한 값과 축 범위를 명시한다. 3D, 그라데이션, 무지개 팔레트와 장식적 배경은
사용하지 않는다.

## 저장과 최종 확인

노트북 파일명의 확장자를 제외한 이름으로 전용 출력 디렉터리를 만든다.

```python
from src.path import create_output_directories

FIGURES_DIR, TABLES_DIR = create_output_directories(
    "YYMMDD_분석목적.ipynb"
)

figure.savefig(
    FIGURES_DIR / "descriptive_name.png",
    dpi=300,
    bbox_inches="tight",
)
```

- 파일명은 그림 내용을 설명하는 영문 `snake_case`를 사용한다.
- 결과표는 같은 노트북 전용 출력 경로의 `tables/`에 저장한다.
- 저장한 실제 파일을 열어 한글, 마이너스 기호, 잘림, 겹침을 확인한다.
- 축, 단위, 범례와 데이터 레이블이 같은 정보를 중복하지 않게 한다.
- 그림만 보아도 비교 대상과 가중 여부를 오해하지 않는지 확인한다.

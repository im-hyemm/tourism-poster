# 연고방문객의 관광 전환을 통한 지역관광 활성화 전략

> 연고방문 수요를 관광활동과 지역 소비로 연결하기 위한 데이터 기반 정책 지원 후보 지역 선정

**2026.06.29 - 2026.07.27 | 2인 팀 프로젝트 | 2026년 관광데이터 분석 포스터 공모전**

[결과 보고서 PDF](<docs/[전혜민]_연고방문객의 관광 전환을 통한 지역관광 활성화 전략_결과물.pdf>)

## 프로젝트 소개

지역소멸에 대응하려면 새로운 관광객을 유치하는 것뿐 아니라 이미 지역을 찾는
사람이 더 오래 머물고 소비하며 관계를 이어가도록 만드는 접근도 필요합니다.
이 프로젝트는 가족·친지·친구를 만나기 위해 지역을 방문하는 **연고방문객**을
지역관광의 잠재 수요로 보고, 이들의 방문을 관광활동과 지역 소비로 연결할 수
있는 지역과 정책 방향을 찾았습니다.

연고방문객을 관계인구 그 자체로 단정하지 않고, 지역과의 기존 관계를 바탕으로
**관계인구로 발전할 잠재력이 있는 방문자**로 정의했습니다. 2023~2025년
국민여행조사를 중심으로 연고방문의 규모와 행동 특성을 분석하고, 관광·상권·교통
데이터를 결합해 인구감소지역의 관광전환 여건을 비교했습니다.

## 핵심 결과

| 기준 | 분석 결과 | 의미 |
| --- | --- | --- |
| 2023~2025년 국민여행조사 가중 추정 | 전국 연고여행 누적 약 **2억 2,210만 회**, 이 중 **31.8%**가 인구감소지역에서 발생 | 인구감소지역에 이미 상당한 연고방문 수요가 유입되고 있음 |
| 2025년 국내여행 가중 추정 | 관광결합·단순 연고방문이 전체 국내여행의 **23.22%** | 연고방문은 별도의 관광정책 대상으로 검토할 만한 규모임 |
| 2025년 가중 1인 평균 지출 | 관광결합 연고방문 **115,251원**, 단순 연고방문 **73,339원** | 관광활동이 결합된 연고방문은 1인당 지출이 **41,912원** 높음 |
| 분류모형 SHAP 해석 | **소비·숙박·동반 방식**이 일반 관광과 연고관광을 구분하는 주요 영역 | 숙박비 지원보다 동행·식음·체험을 연결하는 정책이 적합함 |
| 사전층화 군집분석 | 당일여행 2개, 숙박여행 3개의 **5개 행동 유형** 도출 | 방문자의 행동 유형에 따라 필요한 관광 공급을 다르게 설계할 수 있음 |
| 지역 지원 우선도 | **문경시·금산군·밀양시**를 주요 후보로 선정 | 수요와 공급 여건에 따라 즉시실행형과 기반보강형으로 지원 방향을 구분 |

## 분석 과정

```text
3개년 데이터 통합
→ EDA
→ 분류모형·SHAP 해석
→ 당일·숙박 사전층화 군집분석
→ 시군구 관광·상권·교통 피처 구축
→ 관광전환 지원 우선도 산출
→ 사례지역 정책 적용
```

### 1. 국민여행조사 3개년 통합

연도별로 달라진 문항과 응답코드를 공통 체계로 맞추고, 2023~2025년
국민여행조사를 **156,050행**의 통합 데이터로 구축했습니다. 연고방문은 관광·휴양
활동을 포함한 방문과 단순 가족·친지·친구 방문으로 구분했습니다.

### 2. 연고관광 특성 분석

일반 관광·휴양 여행과 관광활동이 결합된 연고방문을 분류하는 모델을 학습하고
SHAP으로 예측 기여도를 해석했습니다. 최종 모델의 Test 성능은 **F1 0.672**,
**ROC-AUC 0.867**이었으며, 소비·숙박·동반 특성이 두 여행을 구분하는 핵심
영역으로 나타났습니다.

### 3. 연고방문 행동 유형화

숙박 여부가 세부 행동 차이를 가리지 않도록 당일여행과 숙박여행을 먼저 나눈 뒤
군집분석을 수행했습니다. 당일여행에서는 가족동반 체험·활동형과 저활동 일반
당일형, 숙박여행에서는 대규모 동행 체험·소비형, 1인·대중교통 생활소비형,
소규모 동행 일반 숙박형을 도출했습니다.

### 4. 지원 후보 지역 선정

전국 229개 시군구의 연고방문 수요와 관광전환 필요를 **전환 잠재력**으로,
방문 유형별 관광·상권·교통 여건을 **공급 준비도**로 구성했습니다. 두 지표를
60:40으로 결합하고 표본 기준과 인구감소지역 조건을 적용해 지원 후보를
선정했습니다.

| 순위 | 지역 | 지원 우선도 | 지원 유형 | 대표 방문 유형 |
| ---: | --- | ---: | --- | --- |
| 1 | 경상북도 문경시 | 56.0 | 즉시실행형 | 소규모 동행 일반 숙박형 |
| 2 | 충청남도 금산군 | 55.3 | 기반보강형 | 저활동 일반 당일형 |
| 3 | 경상남도 밀양시 | 55.2 | 즉시실행형 | 소규모 동행 일반 숙박형 |

## 정책 적용 사례: 문경시

문경시는 전환 잠재력과 공급 준비도가 모두 높은 즉시실행형 지역입니다. 기존
관광 프로그램을 새로 만드는 대신, 가족·친지·친구 단위 방문객이 기존 일정에
관광활동과 식음 소비를 더하기 쉽도록 다음과 같은 개선 방향을 제안했습니다.

- **함께 찍는 문경 스탬프**: 기존 스탬프투어에 동행 공동 미션과 주변 식음시설
  선택 미션 추가
- **문경 달빛사랑여행: 같이 걷는 문경**: 관계·동반자 정보를 수집하고 사진·이야기
  미션과 주변 식음정보 제공
- **문경에서 만나요**: 가족·친지·친구·동창 모임을 위한 소규모 단체 시범유형과
  관광지·식사·체험 결합 상품 운영

## 개인 기여

문경시 관광지·식음 POI 분석을 제외한 분석 전 과정을 담당했습니다.

- 국민여행조사 3개년 변수 조화와 통합 데이터 구축
- 연고관광 EDA 및 분류모형 비교·SHAP 해석
- 당일·숙박 사전층화 군집분석과 Lift 기반 유형 해석
- 시군구 관광·상권·교통 피처 구축과 지역 정합화
- 관광전환 지원 우선도 설계, 후보 지역 선정과 정책 방향 도출
- 분석 결과 정리와 보고서·포트폴리오 구성

## 저장소 구조

```text
tourism_poster/
├─ data/          # 원자료 디렉터리 구조와 전처리 결과
├─ notebooks/     # 01_Preprocess부터 07_Cross까지 단계별 분석
```

| 경로 | 역할 |
| --- | --- |
| `data/` | 원자료의 디렉터리 구조와 분석용 전처리 결과를 관리합니다. 실제 데이터 파일은 Git에서 추적하지 않습니다. |
| `notebooks/` | 전처리, EDA, 분류, 군집화, 지역 피처, 점수화, 교차해석 순서로 분석 노트북을 보관합니다. |
| `script/` | 주요 분석 노트북을 재구성하거나 동기화하는 Python 스크립트를 보관합니다. |
| `src/` | 공통 경로, 시각화 설정과 노트북 생성 보조 기능을 관리합니다. |
| `docs/` | 공모전 결과 보고서와 분석에 참고한 문서를 보관합니다. |
| `outputs/` | 보고서와 포트폴리오에 사용한 표·그래프를 노트북별로 저장하는 로컬 디렉터리입니다. |

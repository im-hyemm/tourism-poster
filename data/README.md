# 데이터 안내

이 디렉터리는 `연고 방문을 활용한 지역관광 활성화 전략` 분석에 사용하는
원자료, 원자료에서 직접 만든 공간 보조자료와 전처리 결과를 보관한다.

## 관리 원칙

- `raw/`에는 외부에서 내려받은 원자료와 원자료에서 직접 변환한 공간
  보조자료를 둔다.
- CSV·SHP 등을 GeoJSON으로 변환하거나 주소를 지오코딩한 파일은 엄밀한 의미의
  원본은 아니지만, 원자료와 함께 읽기 전용으로 보관한다. 변환 과정은 아래
  출처표와 관련 노트북에 기록한다.
- `preprocess/`에는 분석 코드로 생성한 통합본, 파생변수, 분석용 테이블을 둔다.
- `raw/`의 파일은 수정하거나 덮어쓰지 않는다. 명칭 정규화와 좌표계 변환 등은
  코드에서 수행하고 결과는 `preprocess/`에 저장한다.
- 프로젝트 코드에서는 개인 절대경로를 쓰지 않고 `src/path.py`의 공통 경로를
  사용한다.
- 실제 데이터 파일은 크기와 형식에 관계없이 Git으로 추적하지 않는다. Git에는
  이 문서와 디렉터리 유지를 위한 `.gitkeep`만 올린다.
- 원자료를 새로 받을 때는 제공기관, 자료명, 기준 시점, 다운로드일과 원본
  파일명을 확인한다. 같은 URL에서 최신 자료가 제공되더라도 분석에 사용한
  스냅샷을 임의로 교체하지 않는다.

## 디렉터리 구조

```text
data/
├─ raw/
│  ├─ national_travel_survey/  # 2023~2025년 국민여행조사와 보조 코드
│  ├─ pop_decline_danger/      # 인구감소지역 명칭 목록
│  ├─ sigungu_map/             # 시군구 경계 공간자료
│  ├─ store/                   # 시도별 상가(상권)정보
│  ├─ tour_site/               # 전국 관광지 공간자료
│  └─ transportation/          # 버스·철도·고속도로·터미널 자료
└─ preprocess/
   ├─ national_travel_survey/  # 국민여행조사 통합·전처리 결과
   ├─ classification/          # CASE 1·2 분류용 데이터와 메타데이터
   └─ features_by_region/      # 시군구 단위 관광·상권·교통 집계표
```

## 원자료 출처와 저장 방법

### 국민여행조사

| 항목 | 내용 |
| --- | --- |
| 제공기관 | 한국문화관광연구원 관광지식정보시스템 |
| 출처 | [국민여행조사 데이터 다운로드](https://know.tour.go.kr/stat/nRawDataDownloadDis19Re.do) |
| 사용 자료 | 2023·2024·2025년 국민여행조사 국내여행 원자료와 코드북 |
| 저장 위치 | `raw/national_travel_survey/y2023/`, `y2024/`, `y2025/` |
| 입수 방법 | 개인정보 이용 동의와 데이터 신청자 정보를 입력한 뒤 연도별 압축파일을 내려받아 해당 연도 폴더에 푼다. |

SAV 원자료는 응답자 기준 가로형 자료다. 원본과 코드북은 읽기 전용으로
관리하고 Git이나 공개 저장소에 올리지 않는다. 연도별 SAV에서 추출한 코드북과
지역코드 CSV도 같은 연도 폴더에 둔다.

`raw/national_travel_survey/national_travel_survey_region_code.csv`는 독립적인
범용 행정구역 코드가 아니라 2023~2025년 국민여행조사의 방문지역 코드를
해석하기 위해 만든 공통 보조자료다. 연도별 지역코드는
`notebooks/01_Preprocess/260719_국민여행조사_지역코드_연도비교.ipynb`에서
비교한다.

### 인구감소지역

| 항목 | 내용 |
| --- | --- |
| 제공기관 | 행정안전부 |
| 출처 | [인구감소지역 지정](https://www.mois.go.kr/frt/sub/a06/b06/populationDecline/screen.do) |
| 로컬 파일 | `raw/pop_decline_danger/pop_decline_danger_region.csv` |
| 생성 방법 | 공식 웹페이지의 인구감소지역 지정 현황 89개 시군구를 `sido`, `sigungu` 두 열로 정리한다. |

이 파일은 지정지역 명칭 목록으로만 사용한다. 인구감소 정도, 위험 점수, 지정
사유나 순위를 뜻하지 않는다.

### 관광지와 상가정보

| 자료 | 제공기관·출처 | 저장 위치와 처리 |
| --- | --- | --- |
| 전국관광지정보표준데이터 | 문화체육관광부·[공공데이터포털](https://www.data.go.kr/data/15021141/standard.do) | 공식 표준데이터를 내려받아 관광지 유형을 추가하고 공간자료로 변환한 `raw/tour_site/전국관광지정보표준데이터_관광지유형추가.geojson`을 사용한다. |
| 상가(상권)정보 | 소상공인시장진흥공단·[공공데이터포털](https://www.data.go.kr/data/15083033/fileData.do) | `상가(상권)정보_20260331` 배포본을 내려받아 시도별 CSV와 업종분류코드를 `raw/store/`에 저장한다. 배포본 표기와 달리 로컬 시도별 파일명에는 기준 시점 `202512`가 포함될 수 있으므로 두 표기를 함께 보존한다. |

관광지 GeoJSON은 외부에서 받은 원본 파일 그 자체가 아니라 관광지 유형 추가와
공간자료 변환을 거친 보조자료다. 유형 분류 기준이나 좌표 생성 방식을 바꿀 때는
기존 파일을 직접 수정하지 말고 재현 가능한 전처리 코드를 남긴다.

미매칭 주소와 수동 보정 내역을 함께 확인한다.

### 시군구 경계

| 항목 | 내용 |
| --- | --- |
| 제공기관 | 통계청 통계지리정보서비스(SGIS) |
| 출처 | [SGIS 자료제공](https://sgis.mods.go.kr/view/pss/openDataIntrcn) |
| 사용 자료 | 2025년 2분기 시군구 경계 |
| 로컬 파일 | `raw/sigungu_map/전국_시군구_2025_2Q.geojson` |
| 변환 방법 | SGIS 경계 SHP를 GeoJSON으로 변환하고 EPSG:4326으로 저장한다. |

GeoJSON에는 `BASE_DATE`, `SIGUNGU_CD`, `SIGUNGU_NM`만 있고 시도명은 없다.
`SIGUNGU_CD` 앞 두 자리로 시도명을 만들며, 시군구명만으로 전국 자료를 결합하지
않는다. 도시 단위 표와 결합할 때는 구 단위로 분할된 12개 시를 `dissolve`한다.

전처리 결과는 공식 기관에서 내려받는 별도 원자료가 아니라 이 프로젝트에서
생성한 산출물이다. 핵심 수치나 생성 규칙을 바꾸면 관련 노트북을 처음부터 끝까지
다시 실행하고 행 수, 키 중복, 결측과 미매칭을 확인한다.

## 지역자료 결합 주의사항

- 국민여행조사 지역코드는 `시도_코드 + 시군구_코드` 복합키로 사용한다.
  `시군구_코드` 단독으로 결합하지 않는다.
- 인구감소지역의 시도 약칭을 정식 시도명으로 변환한 뒤 시도명·시군구명
  복합키로 결합한다.
- 국민여행조사 전용 지역코드는 군위군을 경상북도로 분류하지만, 인구감소지역
  목록과 2025년 경계자료는 대구광역시로 분류한다. 기준 시점을 정해 결합 직전에
  명시적으로 보정한다.
- 국민여행조사 계열 자료의 인천 남구와 경계자료의 미추홀구 명칭 차이를
  확인한다.
- 결합 전후 행 수, 복합키 중복과 미매칭 목록을 기록한다. 원자료를 직접 고치거나
  미매칭 지역을 임의의 인접 지역으로 대체하지 않는다.

## Git 관리

`data/` 아래 실제 데이터는 모두 로컬 전용이다. `.gitignore`는 데이터 파일을
제외하고 다음 파일만 추적하도록 설정한다.

- `data/README.md`
- `data/` 아래 각 디렉터리의 `.gitkeep`

이미 Git이 추적하고 있는 데이터는 `.gitignore`를 추가해도 자동으로 추적이
해제되지 않는다. 원격 저장소에 올리기 전 Git 인덱스와 로컬 커밋 이력에서
대용량 데이터가 제거되었는지 별도로 확인한다. 데이터 파일을 `git add -f`로
강제 추가하지 않는다.
